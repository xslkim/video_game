# 《长安灯妖录》单次街景与受击光效验收

Windows x64 三节点试玩。解压 `dist/Changan-Market-Windows-x64.zip` 后双击 `Changan.exe`。本地已解压的入口是 `dist/Changan-Market/Changan.exe`。[操作与回放命令](PLAY_CHANGAN_M0.md)

## 行人为什么回跳

上版把街景与妖怪合成在同一条视频里。怪物再次攻击、切到受击镜头或返回待机时，行人也跟着进入另一段表演。这个版本为整次巡街单独生成了一条固定机位的 H3 街景，共 175 帧，24 fps，约 7.3 秒。行人走到摊位旁停下。播放器只在新开局从第 0 帧开始，走到第 174 帧便释放街景解码器，保留最后一张纹理。暂停会冻结街景，快速通关时街景可以在结算画面后方自然收尾。

12 段妖怪表演与街景独立播放。青火在第 37 帧发射，第 38–67 帧可拦截，第 68 帧抵达。碰撞检测读取显示帧对应的命中蒙版，石板反光和空中火花都不会扩大可打范围。背景制作参数可在 `worlds/changan/m0/production/street_once_job.json` 中复核。

## 哪一层截掉了特效

对照 H3 原片、旧版合成和本次成片，旧版在提取前景时裁掉了青火爆裂左侧、地面倒影和狐火照亮屋檐的部分。现在从原片的整个画幅提取发光、色偏和反光，将它们与妖怪一起写入带预乘透明度的无损 FFV1 前景。引擎绘制的命中圆环和粒子各自保留 0.45 秒，命中、换匣和切镜可以重叠。

为核对柔光，分别取青火前方地面和狐火上方夜空，对比该帧与效果消退后的画面。下表是采样区域内正向通道亮度变化的均值，单位为 8 位色阶。地面取绿通道，夜空取红通道。

## 试玩包复核

从 ZIP 解压至带中文和空格的目录，在包外启动程序。素材检查覆盖 12 段前景、1 段街景、7 份命中蒙版、画幅、帧数、像素格式、音轨和 SHA-256。无效街景时长、坏哈希、冲突的街景时间线、断开的分支和越界的命中窗口均被拒绝。西部游戏的 CTest 规则回归通过，共用解码器的西部版正常路线也在 Windows 上运行了 61.12 秒并通关。

Windows 实机自动回放共 15 条，全部通关。覆盖正常、早晚命中、三个灯笼妖出手分界、三种青火拦截、抵达受伤、两种雷符、失败恢复、等到两次受击和命中后立即换匣。

| 操作 | 实测结果 |
|---|---|
| 分别让灯笼妖和青火攻击一次，再连续命中狐妖 | 余 1 命通关。末帧之后连续 258 张实录采样的街景索引均为 174。跨 8 次循环或切镜，在两侧行人区域跟踪特征，位移中位数最大为 0.023 像素 |
| 命中灯笼妖后立即换匣 | 命中后约 0.100 秒开始换匣，圆环一直保留到命中后约 0.461 秒的首个到期检查 |
| 青火飞行途中施符 | 第 38、53、67 帧分别进入早、中、晚拦截镜头，三条路线均余 3 命。等到第 68 帧会损失 1 命 |
| 暂停、继续、重试、快速通关 | 暂停期间采到的 5 张图对应相同的街景帧和视觉时钟。每次重新开局从第 0 帧起播，15 条路线结算时均已到第 174 帧并释放背景解码器 |

播放器实录和证据位于 `dist/Changan-Market-Preview`。

- `once-hit-comparison.jpg` 展示两个版本实际呈现的同一逻辑帧，分别为青火拦截第 3 帧和狐火净化第 31 帧。
- `once-validation.zip` 包含 15 条回放的事件、截帧索引、镜头切换和汇总测量。
