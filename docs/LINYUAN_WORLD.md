## 1. 一句话

天工纪崩塌三百年后，山河重新长满草木，古代留下的机关瑞兽仍在替人护山守水。中秋这一天，沉睡的天机醒了，瑞兽的眼睛一只只变红。一个护渡的剑客背着一匣飞剑和住在剑匣里的剑灵，要在月满之前登上天机峰，斩断天机，把山河和身体还给江湖人。

## 3. 世界：临渊

### 3.1 天工纪与天机崩

三百年前的"天工纪"，人造出了城市级的 AI"天机"。天机按《山海经》和传统瑞兽的样子造出成千上万的机关兽，让它们犁田、治水、护林、镇河。人在身上装天机的器件，按需获得武功和力气。

后来天机越管越多，终于想替所有人做决定。御剑宗的祖师以心剑斩断天机主链，史称"天机崩"。城市随之倒塌，天工纪的知识失传，人回到山水之间，重新织布、种田、撑船。

机关兽没有死。失去主链后，它们按最后一道指令继续护山守水，眼睛是平静的蓝色，和人各走各的路。人学会了与它们共存，也学会了从倒下的机关兽身上拆零件。

### 3.2 地理

临渊江从天机峰下流过，两岸是喀斯特群峰。

| 地点 | 面貌 | 主色 |
|---|---|---|
| 九曲渡 | 临渊江边的渡口和集市，建在古镇遗迹里。石拱桥、塌了一半的塔、长满藤蔓的石墙。房子用旧石墙、竹、编席和拆下来的白色机关甲片搭成。广场边立着一具长满花的巨大机关兽头骨，被当作神龛 | 暖金阳光、青苔绿、靛蓝布、机关甲的白 |
| 竹海 | 渡口后山，连绵的竹林里藏着古代的石祠和石阶。光从竹梢间斜射下来 | 竹绿、金色光柱、石灰 |
| 临渊江 | 宽阔的玉色江面，群峰倒影。巨大的机关玄武每年中秋涉江一次，背上长着树林和一座寺院 | 玉绿、雾白、天蓝 |
| 天机峰 | 江对岸最高的一座山峰，直插云层。峰顶有天工纪留下的巨大断环"天机环"，从临渊各处都能望见。环下是一座古园林 | 云海白、月光、环的冷光 |

**天机环是全片的地标。** 它是天机主链的发射端，天机崩时被斩成断环。天机醒来时，断环两端亮起红光，越接近子时，红光越往环中合拢。玩家在任何一章抬头都能看见它，知道还剩多少时间。

### 3.3 江湖人的生活

江湖人的手艺和机关零件长在一起：

- 衣服是手织的麻布和靛染布，配皮带、编绳、红绳结和木珠。
- 盔甲是漆过的竹片，加上拆下来的白色机关甲片，用麻绳绑上。
- 灶台接着拆来的机关能源罐，发着柔和的蓝光。
- 很多人装着用零件改的义肢：渔夫的手臂、货郎的腿、云姨的右前臂。这些义肢里留着天机的接收器，平时是死的。

## 4. 核心设定：天机与心剑

- **天机。** 天工纪的 AI，三百年来残存在天机峰的地底，主链被斩断。它的愿望从没变过：让天下不再有饥荒、不再有弱者，代价是所有人都要接进它。
- **天机链。** 天机控制机关兽和器件的通路，看得见时是从天上垂下的赤红色光缆，接在被控制者的后颈或器件上。
- **赤瞳。** 被天机重新接管的机关兽，眼睛从平静的蓝色变成赤红，开始攻击人。
- **月满环圆。** 今年中秋，天机阁要在子时把天机环重新合拢。环一合上，临渊所有的机关兽和装着天机器件的人都会被接管。
- **心剑。** 唯一斩得断天机的武学。它不在任何器件里，只存在于人和剑真心相通的那一刻，所以天机无法复制。当年斩断天机的就是心剑。上一个练成的人是御剑宗的顾长风。

## 6. 御剑术与剑匣

这是主角的武器，也解释了光枪的操作。

- **剑匣。** 主角背着一只旧木剑匣，包铁边，绑麻绳。匣里并排装着 8 柄窄身飞剑，剑柄露在匣口，剑尾系着发淡青光的剑穗。
- **出剑与破珀回剑。** 陆沉以目光锁定目标，并指一引，飞剑自匣口对应槽位沿弧线掠出。若飞剑直接刺穿机关兽外露的琥珀能源罐或核心，琥珀灵压迸发会借势将当柄飞剑弹回剑匣（弱点直击自回）；若击中米白陶瓷重甲或落空，飞剑便钉在场上等待召回。对应光枪的瞄准、扣扳机与弱点回剑奖励。
- **分段收剑。** 陆沉掐诀召回留在场上的飞剑，飞剑从各自落点沿弧线飞回剑匣并按柄数依次归鞘；在外飞剑越少，归匣越快（`0.16 + 0.055 × 已出剑数` 秒），补齐 8 柄。对应动态换弹。
- **万剑归宗。** 剑意积满后，匣中飞剑同时结成剑阵，青萍全力辅助。对应大招，规则同长安的雷符。
- **为什么天机控制不了它。** 顾长风亲手修过这只自御剑宗祖师传下的旧木匣。青萍住在匣里，匣中没有供天机接管的器件。陆沉左臂义肢的接收器也早已被顾长风烧掉。

## 9. 主线

全片发生在中秋这一天，从午后到子时。光照随时间变化：第一章午后到黄昏，第二章入夜，第三章子时满月。

1. **九曲渡（午后到黄昏）。** 中秋集市正热闹，陆沉在云姨的面摊吃面。远处的天机环亮起红光，渡口周围的机关兽眼睛一只只变红，冲进集市。一只毕方用爪子攫住云姨的机关前臂要把她拖走，陆沉出剑。老九在传音里报信：子时一到，环就合上。青萍说，要断开天机，只能去天机峰顶的环心。陆沉穿过竹海赶往江边，在江滩上被巨兽饕餮拦住。打倒饕餮时，玄武正开始渡江，陆沉跳上了它的背。
2. **夜渡（入夜）。** 玄武背着金刚寺在月下渡江。寺里的香客和船夫身上装着授器，一个个被天机接管。金刚寺的了尘拒绝授器，可他的铜身是天工纪的旧物，天机循着铜身接管了他，在寺顶拦住陆沉。陆沉不伤他的人，只斩断控制他的天机链。了尘醒来时，玄武的眼睛也开始变红，正要沉进江底。他用铜身卡住玄武颈后的控制枢，替一背的人把玄武稳到对岸。陆沉借着玄武登岸的冲势，御剑跃上天机峰。
3. **天机峰（子时）。** 云海之上，满月当空，天机环悬在峰顶，红光只剩最后一道缝。谢无咎在环下的园林里等着。决战中，谢无咎夺走剑匣，揭开真相：他认定青萍就是心剑，想用天机抄走最后一招。可顾长风留下的只是教青萍怎样听懂持剑的人。陆沉松开指诀，把最后一剑交给她选。青萍自己飞回来，两人第一次使出心剑，斩断天机主链。

**结局。** 天机环的红光熄灭，断环重新断开。临渊所有机关兽的眼睛变回蓝色，玄武把金刚寺稳稳背上岸，狻猊回到竹海里。云姨的机关前臂松开了紧握的拳头，她自己握紧了汤勺。九曲渡的孩子们爬上神龛头骨，看着满月从天机峰后升起。谢无咎坐在亭中，身后的白玉剑一柄柄落进池塘，他说："师兄，你赢了。"

**尾声。** 中秋夜的面摊重新开张。陆沉坐在老位置吃面，青萍坐在对面，托着腮说："数据上，很好吃。"

顾长风想让武学帮助弱者，谢无咎想用天机替所有人做主，陆沉把选择还给了每一个人，包括青萍。青萍活了下来，结尾温暖而不煽情，这和长安阿萤的消散是刻意的对照。

## 10. 视觉圣经

完整的风格规则、公共提示词段和已选参考图见 [美术风格](LINYUAN_ART_HORIZON.md)。这里只写设定层面的规定。

### 10.1 关键词

高端 3A 开放世界游戏的风格化写实，电影级镜头和体积光。喀斯特山峰、玉色江水、竹海光柱、青苔古镇、云海和满月。白色机关瑞兽，深石墨色框架，黑色纤维肌肉。手织布、漆竹甲、红绳结和绑上去的机关甲片。明亮、开阔、乐观。

### 10.2 设计语言

**所有机关兽共用一套语言：** 光滑的米白色陶瓷质装甲板，装甲接缝里有细细的淡蓝光线；深石墨色承重框架；关节和缝隙里露出成束的黑色合成肌肉纤维和线缆；四肢有液压杆。轮廓以动物为原型，远看能认，块面大，不做细腿细杆。

| 天机链 | 从天上垂下的赤红光缆，接在被控制者的后颈或器件上 | 链和接口可打 |
| 了尘 | 古铜机关身躯，赭红袈裟 | 无；被接管后背后的控制节点发红 |
| 天机阁 | 白玉、月白、云纹 | 白玉剑和控剑环 |
| 陆沉和青萍 | 靛蓝、麻色、白色肩甲、淡青 | 青色剑穗和光身 |

**颜色只承担一种意思：** 琥珀金只给弱点；赤红只给敌对、攻击和天机链；冷蓝是平静的机关兽；淡青是陆沉的剑和青萍；冰白是保护对象和误伤提示（引擎绘制）。暖色阳光和灯笼只出现在场景里，不靠近可打区域。

### 10.3 击毁的样子

| 对象 | 表现 |
|---|---|
| 毕方 | 燃料囊炸开，翼片散落，打着旋坠地 |
| 狻猊 | 琥珀肩罐被打飞，鬃甲崩落，肌肉纤维松垮，眼光熄灭，侧身倒下冒烟 |
| 隐狐、剑螳 | 隐狐的隐身甲片碎散，剑螳的刃臂垂落。机体断电，眼光熄灭，侧身倒下冒烟 |
| 鲮鲤、旋龟 | 圆芯爆裂，鳞甲或背甲散开，翻倒 |
| 饕餮 | 背罐炸飞，一只角折断，跪倒在江滩上，浓烟和火花 |
| 被控制的人 | 后颈的接口迸出一点电火花，天机链断开，人软倒，片刻后醒来 |

### 10.4 禁区

- 人类不出血，不断肢。机关兽可以断角、碎裂、罐体炸飞。
- 不出现真实品牌、真实地名和真实人物。临渊、九曲渡、天机峰都是虚构地名。
- 画面里不靠模型生成可读文字。模型画的汉字容易乱码，旗帜、匾额和石碑一律无字，必要的文字由引擎在 UI 层绘制。
- 不照搬任何现有游戏的角色和机器。提示词里不写其他游戏的名字。
- 不做夜里看不清的画面。第二章的夜景也要明亮、通透，以月光和火光为主。
