# 尘溪镇 · Windows 首分钟试玩

运行解压目录里的 **DustCreek.exe**，点击「开始巡街」或按 Enter。请保留同目录的 DLL、`assets/` 和 `worlds/`。需要 Windows 10/11 x64。游戏从自身目录读取素材，可以离线运行。

| 操作 | 鼠标与键盘 |
|---|---|
| 开火、选择菜单 | 鼠标左键 |
| 换弹 | 鼠标右键或 R，耗时 0.5 秒 |
| 跳过镇长序幕 | 空格 |
| 暂停、恢复 | Esc，窗口失焦也会暂停 |
| 全屏、字幕 | F11、C |
| 切换鼠标 / TVGun | 在标题页点击输入设备或按 F2 |

玩家有 3 条生命、6 发弹药。马车和木桶是前两个节拍。杂货店店员举手经过时保持克制，红领巾角色出场后可继续。酒馆出现独立的金色解救星徽和红色保护标记。选择金色星徽完成解救，误选红色标记扣一条生命。摆门打开后显示本次结果，可重新开始。生命耗尽后可以从当前站位续关。

## TVGun 手机输入

电脑与安卓手机连接同一个局域网，在标题页选择 TVGun，手机进入 TVGun 游戏模式，对准显示器白框。游戏支持 UDP 8001 发现、UDP 9000 输入、`FRAME 24,48` 回包及手机的开始、换弹和退出控制。电脑防火墙如提示，按所用的专用网络授权。失锁会暂停，重新定位后按开始或点继续。已锁定时，向完整定位框外触发也可换弹；框内留黑处不参与交互。

当前已有本机协议回放与 UDP 环回测试。手机与电视端到端延迟、电视尺寸下的远景可读性、马车教学片的内部剪点观感须用实际设备复核。

## 从源代码构建

在仓库根目录执行以下 PowerShell 命令。使用 Visual Studio 2022 的 C++ 桌面工具、CMake、Python 3、Git LFS 和 vcpkg。首次构建需取得锁定的依赖，首批素材需在同一 checkout 或可访问的 LFS 存储中。标准玩家包不需要这些开发工具。

```powershell
.\tools\player\build.ps1 -VcpkgRoot C:/vcpkg
.\dist\DustCreek\DustCreek.exe
```

vcpkg baseline 由仓库的 `vcpkg.json` 锁定。FFmpeg 动态链接，只启用视频与音频解码相关组件。播放器使用 SDL3 的 OpenGL 渲染器，初始化失败时尝试 SDL 可用后端。混音输出统一到 48 kHz 双声道，系统中文字体用于运行时界面。输出目录附有第三方库的版权说明。

## 验证与调试

- `python tools/player/check_opening.py` 检查 26 个片段、15 张规范帧、状态图、交互窗口和掩码绑定。源文件是仓库中签入的最终 MP4。修改成片后需重新审核窗口和标注。
- `ctest --test-dir build -C Release --output-on-failure` 验证规则、30/60Hz 输入回放和真实 UDP 环回收发。
- `DustCreek.exe --smoke <输出目录>` 使用实际播放器、音轨和 SDL 鼠标事件完成一次完整巡街，生成结果 JSON 和首尾截图。可追加 `--early` 验证提前完成，或 `--recovery` 验证耗尽弹药、教学超时、误伤、死亡、续关与受惊。
- `--root <目录>` 指定含 `assets`、`worlds` 的开发目录。`--tv` 启动 TVGun 模式。`--cut` 关闭衔接淡化，`--fade-one` 使用一个显示帧，默认两个显示帧。
- 修改交互素材时，使用 Python、NumPy 和 OpenCV 运行 `python tools/player/masks.py` 重新生成标注，随后检查叠图和边界。普通目标与店员使用半分辨率逐帧可见轮廓，遮挡、窗口和钱袋由各自所在画面限定；酒馆星徽和保护标记使用独立的游戏图形判定。
