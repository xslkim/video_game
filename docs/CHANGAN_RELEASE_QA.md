- 灯贩、火球、精英、多击、换匣和雷符在第一章与 A1 长版共用原视频层。街景向前播放，到末帧停住。前景受击光独立完成。

## 画面与声音

包内有 194 个剧情、战斗或回应视频 ID，其中 80 份逐帧区域绑定成片 SHA-256。另有街战片和独立街景共 35 个文件，按内容去重为 35。正式桌面包全部 229 个视频文件的画面与随片音轨均已解码至末尾。剧情母版 1280 × 720、24 fps，本机 H3 生成后剪辑调色。街战可独立播放怪物和街景，剧情与分阵战斗使用整幅镜头，播放器按已显示帧处理瞄准与反馈。

补拍包含 51 个战斗变体、21 段受击回应和两批各 28 段剧情延伸。九盏龙舟信号从 H3 原片分色。青火、伞面、关节与纸鹤依据实际显示帧校过区域。移除两段成片的模型文字，并调整两处跨镜顺序。抽帧图、人物与五类精英对照图在 Verification/Art。

包内 70 个独立 WAV 均已读取并测量有效电平，包括 17 首 ACE-Step 配乐、23 条独立对白、30 个 Stable Audio Open 拟音（10 类、每类 3 个版本）。阿萤采用本机 VoxCPM2，玄烛等角色采用 Qwen3-TTS；对六段关键对白做了 LatentSync 口型处理。其余对白包括画外音和角色短提示。中文识别把个别人名写成同音字，字幕按剧本保留。新镜头、人物嗓音及剪辑由制作方依照已确认的写实方向选用，五章最终版仍待玩家主观试玩。

制作账本从保存的 ComfyUI 历史中找到 285 个有开始和成功事件的 H3 作业，合计约 136 分钟执行墙钟。表中按批次列出作业 ID、种子、原片和成片哈希。这一口径含中间运动层与候选，未计全部失败重试、音频模型、标注和编码工时。

现代设备优先播放 960 × 540 的 H.264。如果解码器返回错误或画面时钟停滞，会在同一镜头切到离线帧页，保留当前生命、弹药、多击进度与实际目标。手机 API 36 的正式全程测试中，西市千面傀在第 60 帧停滞，84 毫秒后显示同一镜头的离线帧，随后继续完成各章。到大雁塔时已在使用离线帧，预设的大雁塔故障点没有再次触发切换。还用已签名 APK 内的原始网页资源模拟开场媒体解码错误，验证后续多个镜头连续播放。老电视先尝试系统播放器。Android TV 5.1 原装 WebView 39 与软件 H.264 解码器在本机无法可靠输出连续画面，游戏自动换用从同一 H3 原片导出的离线帧页，互动保持每秒 24 帧，剧情每秒 12 帧；已逐项对比两端章节图、80 份成片区域、21 份街战掩码和 1561 页离线画面。判定帧与原片对齐。旧 WebView 的音频解码线程曾在西市镜廊崩溃，兼容路径将声音改由 Android 原生播放器管理，默认使用省电画质。API 22 的街战提示音维持原始播放速度。手机触屏、手柄开始与暂停、两档画质和 TVGun 局域网协议均做了专项检查。

控制器 APK 已在 API 36 安装并冷启动，界面可见开始、换弹和雷符键。Android 游戏端通过 UDP 专项验证，屏幕白框实测为 RGB(255, 255, 255)，内衬为 RGB(12, 19, 25)。控制器可发现 `TVGUN_HERE 9000`、协商 `FRAME 24,48`，支持瞄准、施符、换匣、雷符、失锁与恢复。Windows 正式包在自动目标输入关闭的剧情一箭中收到 UDP 坐标，击中灯芯得 1000 分。同一射击序号重复送达只结算一次。另把已有的 1746 帧手机摄影及陀螺记录交给控制器 Java 算法回放，对照 Python 参考，双方有效帧均为 1737，共同全锁帧的准星中位差为 0.571 个规范像素。录制来自控制器项目的既有数据。对实际渲染帧作正面相机取景模拟，手机端 Java 识别器锁住四条边，输出 (962, 542)，画面中心为 (960, 540)。

Windows 在本机 RTX 5090、1920 × 1080 显示环境测试。APK 在 API 22、34、36 的模拟器验证。实体电视型号、2015 年芯片帧率、实体手柄布局、手机摄像头在真实客厅光照下的精度与显示延迟均待实机。本次 ADB 枚举仅返回以上三台模拟设备。
