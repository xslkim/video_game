# 《临渊御剑》游戏方案 v0.1

日期：2026-11-24。片名为工作名。本文是第三款游戏的策划案，世界观、人物和视觉规范见 [世界观](LINYUAN_WORLD.md)。

引擎、生产管线和光枪接入沿用 [PLAN.md](PLAN.md) 与 [长安方案](CHANGAN_PLAN.md) 的框架，运行时直接复用《长安灯妖录》1.0 的战役播放器。本文只写新游戏的设计，以及长安 1.0 交付后得到的教训所带来的改动。西部和长安的代码与素材保留在仓库里，修改共享播放器后两者都要回归。

文中标注"M0 验证"的地方，是还没有实测数据的设计假设，以 M0 的结果为准。

### 1.2 结论与改动

| 问题 | 本作的做法 |
|---|---|
| 剧情膨胀到 58%。补拍的河上追逐、塔顶到宫门和结尾镜头一路累加 | 纯剧情写成硬上限：全片不超过 35%，每章不超过 75 秒（第三章 90 秒）。每章锁镜前按实测秒数核对，超出时删镜头，不靠加战斗来摊薄比例（第 7 节） |
| 对白集中在独立 CG 里 | 能边打边说的对白放进战斗：青萍的提示、老九的无线电，都挂在战斗节点上，不占独立剧情时间（第 10.3 节） |
| 接力等待贴着上限 | 设计目标收紧到 1.2–1.5 秒，单条样本最多 1.8 秒 |
| 生成量估算偏离实际很远 | 生产量直接用长安的实际台账换算（第 11.6 节），每章开工前按待生成片段 ID 重算 |
| 模型生成了底部文字，需要裁掉 | 世界观禁止画面内可读文字（[世界观 §10.4](LINYUAN_WORLD.md#104-禁区)），提示词统一加负面词 |
| 实机始终没测 | 实机验证排进里程碑，需求方提供设备（第 13、15 节） |
| 准星、受击和打击感很差：全部是 1 像素的线和小方块，没有震屏，各种事件的效果几乎相同 | 重新设计整套反馈，见 [反馈与打击感设计](LINYUAN_FEEDBACK.md) |

## 3. 游戏概念

一句话：在雨夜霓虹里御剑破阵，从城底杀上云顶。

体验目标：

1. **帅**：每一剑射出去都有弹道、有声音、有碎裂。白瓷傀儡的面甲碎开，无人机炸进积水。
2. **快**：10 分钟里不冷场。战斗段里连续不可操作的画面不超过 2 秒，剧情段尽量短。
3. **燃**：下城人被欺压，主角一路往上打；了尘的舍身、心剑的一击是两个高潮。
4. **暖**：结尾雨停见月，面馆里一碗面。

和长安的区别：

| 长安 | 临渊 |
|---|---|
| 镜头基本锁定 | 第二章有移动的列车镜头 |
| 保护百姓 | 解救被劫持的人：只打芯片，不打人 |
| 镜子辨真 | 雨中辨真：真身溅起雨花，全息分身被雨穿透 |
| 无 | 借势：射断招牌、管道，砸倒敌人 |
| 伤感结局 | 温暖结局 |

## 5. 玩法

### 5.1 核心循环

```
剧情（短）→ 战斗（接力）→ 剧情一剑 / 短过场 → 战斗 → Boss → 剧情（结尾，留下钩子）
```

- 剧情按段跳过。
- 战斗段里不插入超过 2 秒的不可操作画面。
- 剧情信息尽量放进战斗里的语音事件。

### 5.2 操作

| 动作 | 鼠标 | TVGun | 触屏 | 手柄 |
|---|---|---|---|---|
| 出剑 | 左键 | 扳机 | 点画面 | A 或 RT |
| 收剑 | 右键或 R | 向框外射击，或 RELOAD | 右下角收剑键 | X |
| 万剑归宗 | 中键 | SPECIAL | 右下角大招键 | Y |
| 跳过剧情 | 空格 | START | 点跳过 | START |
| 暂停 | Esc | 失锁自动暂停 | 系统返回 | START |

### 5.3 剑匣

- 一匣 8 柄，普通难度收剑 0.6 秒。
- 判定以扣扳机时正在显示的那一帧为准，不等飞剑"飞到"。飞剑弹道只是 3 帧的视觉表现（第 8 节）。
- 没有射速限制。

### 5.4 万剑归宗

| 项 | 规则 |
|---|---|
| 充能 | 有效命中 +1 格，按难度满 15 / 20 / 25 格，最多存一次 |
| 扣减 | 有效窗口内打空 −2 格；受伤清零 |
| 释放 | 当前小怪直接击毁；精英造成 2 点伤害；Boss 只在有专用暴露分支的阶段可用 |
| 限制 | 纯转场、拦截、解救和剧情一剑期间锁定 |
| 第 3 章心剑 | 剧情强制充满，按普通出剑键释放，使用独立剧情窗口，不占万剑归宗 |

### 5.5 敌人

设计原则：

- 都是非人：遥控傀儡、无人机、机关兽。人形傀儡有面甲和瓷壳，一眼看得出不是人。
- 都有自发光部件，暗场里靠光点找目标，弱点就在光点上。
- 出场即蓄力，蓄力动作清楚。

**小怪**（一剑击毁，接力出现）

| 敌人 | 章 | 行为 | 击毁 |
|---|---|---|---|
| 蜂鸟（巡检无人机） | 1、2 | 从楼缝里飞出，红色镜头亮起后俯冲 | 炸成火花，坠进积水 |
| 铁衣卫（回收傀儡） | 1–3 | 举电击钩蓄电，然后突刺 | 面甲碎裂，断电跪倒 |
| 狻猊（唐门机关犬） | 1、3 | 伏低后扑向镜头 | 关节冒烟，瘫倒 |
| 隐（光学迷彩刺客） | 1、3 | 只露出雨水勾出的轮廓，青萍扫描后才现形 | 迷彩失效，倒地 |

**精英**（2–3 剑）

| 敌人 | 章 | 行为 | 弱点 |
|---|---|---|---|
| 梨花匣（唐门机关师傀儡） | 1 | 背上的匣子张开，射出"暴雨梨花"微型飞弹，要拦截 | 背匣的金色核心 |
| 铁衣卫·盾 | 2、3 | 举全息八卦盾，盾面旋转时打不进；停转时露出胸口核心 | 胸口核心 |
| 剑卫（天机阁剑客傀儡） | 3 | 挥剑格挡飞剑，收剑换势时露出破绽 | 胸口芯片 |

**被劫持者**（不是敌人）

| 对象 | 章 | 规则 |
|---|---|---|
| 被劫持的乘客 | 2 | 双眼泛蓝，后颈连着天机链。只能打后颈芯片或天机链；打中人扣命（简单难度只扣分）。解救后人软倒，片刻醒来 |

### 5.6 特殊机制

| 机制 | 玩法 | 章 | 实现 |
|---|---|---|---|
| 扫描现形 | 隐形刺客只有雨水轮廓；青萍化作青光扫过去，现形后才能击中 | 1、3 | 与长安照妖相同：命中区域从现形帧起生效 |
| 拦截 | 暴雨梨花、罡气、谢无咎射来的飞剑，都可以在飞行中击落 | 1–3 | 沿用长安的投射物窗口：发射、可拦截、抵达分别标帧 |
| 护盾 | 八卦盾旋转、剑卫格挡、了尘的金钟罩，打上去只有跳弹 | 2、3 | 沿用长安的护盾区域 |
| 借势 | 打断霓虹招牌、蒸汽管道，砸倒或喷倒下面的敌人 | 1、3 | 两节点接力：节点 1 的目标是环境物件，命中后播"砸落"片段；奖励 200 分 |
| 解救 | 被劫持的人只打芯片或天机链 | 2 | 沿用长安的附身判定：人身是保护区域，芯片和链是目标区域 |
| 移动镜头 | 列车车顶，背景高速后退，敌人从侧面追上来 | 2 | 分阵 `trial` 的逐帧追踪多边形。若追踪不准，退到车厢内的固定机位，只让窗外背景移动（第 14 节） |
| 顺序 | 谢无咎的 12 柄剑依次亮起，按亮起顺序击落 | 3 | 沿用长安九首龙舟的顺序判定 |
| 雨中辨真 | 三个谢无咎，只有真身身上溅起雨花，分身被雨水穿透 | 3 | 沿用长安镜廊的辨真判定，两个分身任选顺序 |
| 剧情一剑 | 剧情进行到关键时刻放慢，玩家出剑完成主角的动作；命中和失手各有一段短片，最后汇合 | 1–3 | 沿用长安的剧情一枪 |
| 伙伴喊话 | 青萍："左边楼顶！""打它的核心！""小心飞弹！"；老九在无线电里报信 | 1–3 | 新增：语音和字幕事件挂在战斗节点上（第 10.3 节） |

### 5.7 判定

沿用长安：按开枪时正在显示的帧判定；每帧先确定玩法阶段，再查可见区域；同一输入只结算一种结果；辅助瞄准只在敌人轮廓外的窄带内生效，避开被劫持者的人身。

### 5.8 得分和评级

| 项 | 得分 |
|---|---|
| 击毁小怪 | 100 |
| 击毁精英 | 500；打弱点 +200 |
| 拦截 | 150 |
| 借势击毁 | 200 加被砸敌人的分 |
| 解救一人 | 300；一段内无误伤 +1000 |
| 剧情一剑命中 | 1000 |
| 反应加成 | 从首个可命中显示帧起计，最多 ×1.5 |
| 连击 | 每次 +0.05 倍，上限 ×3；打空或受伤清零 |

每章结算：得分、命中率、最高连击、受伤次数、击毁数、解救数，评级 S / A / B / C。通关后给总评。

### 5.9 三档难度

| 参数 | 简单 | 普通 | 困难 |
|---|---|---|---|
| 生命 | 5 | 3 | 3 |
| 敌人攻击前的反应窗口 | ×1.4 | ×1.0 | ×0.65 |
| 拦截窗口 | ×1.3 | ×1.0 | ×0.7 |
| 精英血量 | −1 | 标准 | +1 |
| 辅助瞄准扩张（720p） | 24 像素 | 12 像素 | 0 |
| 收剑耗时 | 0.4 秒 | 0.6 秒 | 0.8 秒 |
| 万剑归宗充能 | 15 格 | 20 格 | 25 格 |
| 误伤被劫持者 | 只扣分 | 扣 1 条命 | 扣 1 条命 |
| 剧情一剑窗口 | 3 秒 | 2 秒 | 1.2 秒 |

每章开始时生命恢复满；续关从当前战斗段开头重来，分数清零。窗口倍率的实现沿用长安：起播偏移和播放速度合计只缩放一次。

## 6. 章节段落

段落类型：**剧情**可跳过；**战斗**是接力射击段；**一剑**是剧情一剑；**Boss** 是整帧分阵。时长是目标值，M0 试玩后调整。

## 7. 节奏和难度硬指标

计时口径沿用长安方案第 7 节：T_hit、T_open、T_input 三个时间，分别报告系统等待和玩家反应。

| 项 | 指标 |
|---|---|
| 普通接力等待 | 1.2–1.5 秒，单条样本最多 1.8 秒 |
| 战斗段内连续不可操作 | 最多 2 秒（剧情一剑的慢放除外） |
| 每章有效出剑 | 普通路线 35–45 剑 |
| 收剑 | 每章至少 4 次是必需的。8 柄满匣起步、没有补给时，第 33 剑使第 4 次收剑成为必需 |
| 可读预警 | 每章至少 12 次 |
| 新内容 | 每章至少一种新敌人、一种新机制 |
| 剧情占比 | 全片不超过 35%；每章剧情秒数见第 6 节，超出就删镜头 |

## 8. 打击感规格

完整规格见 [反馈与打击感设计](LINYUAN_FEEDBACK.md)，包括准星、目标与威胁指示、敌人受击、玩家受击、声音、震屏、万剑归宗和验收方法。要点：

- 长安的反馈全部是 1 像素的线和 3 × 3 的方块，命中、净化、打空几乎是同一个效果，没有震屏，受击只是上下两条红边。本作重做整套反馈。
- 按 L0–L4 五个强度等级统一分配顿帧、震屏、闪光、粒子和声音层数。
- 准星加粗描边，带指向状态和弹药刻度；命中点有命中标记和得分飘字。
- 敌人受击：剑痕弹道、剪影闪白、按材质的火花和碎片、二段闪、冲击环。
- 玩家受击：顿帧、方向光、震屏、色差、按攻击类型的屏幕叠层、生命图标碎裂、全局声音闷压。误伤用冰白色，和受击完全区分。
- 仍用 SDL_Renderer，加贴图、加法和乘法混合、`SDL_RenderGeometry` 实现，不必先换 GL。

## 9. 美术

风格、设计语言和禁区见 [世界观 §10](LINYUAN_WORLD.md#10-视觉圣经)。生产上的补充：

- **雨量分级。** 战斗的锁定机位用中雨，剧情可以用暴雨。暴雨的雨丝在两段片段的接缝处不连续，容易看出跳变（M0 验证）。
- **全息青萍。** 半透明、带闪烁的全息形象，对人脸一致性的要求比真人低，这是本作的生产优势。风险是视频模型可能把她画成实体，M0-B 验证。
- **人脸镜头。** 剧情以中景和全景为主，脸部大特写全片不超过 10 个。
- **一致性。** 沿用长安的五层控制：镜头设计、定妆照加场景编辑首帧、ReferenceToVideo 带定妆照、必要时训练角色 LoRA、人工对照。
- **每章一种光。** 下城是霓虹和面馆暖光，中城是冷白的列车灯和寺庙的金，上城是月光。章与章之间画质漂移不累积。

## 10. 技术方案

### 10.1 画面分层

```
UI（HUD、字幕、剑意槽、蓄力光环、TVGun 白边）
后处理（LUT 调色、暗角、色差、颗粒）
玩家交互特效（飞剑弹道、命中火花、受击、万剑归宗）
整帧视频（战斗、接力转场、剧情、Boss）
```

### 10.2 播放器参数化

长安的播放器把世界路径写死在 `apps/player/changan.cpp` 里（`worlds/changan`、`assets/changan`），CMake 用 `BUILD_CHANGAN` 选项单独构建 `Changan.exe`。改造方式：

- 世界目录、素材目录、标题、存档名、可执行文件名由世界清单给出。CMake 改为按世界名构建，例如 `-DCAMPAIGN_WORLD=linyuan`，同时保留现有的 `BUILD_CHANGAN` 用法。
- 敌人、武器的名称和 HUD 文案从世界数据读取（符箭→飞剑、雷符→万剑归宗、净化→击毁）。
- 回归：西部的普通、提前、失误恢复三条路线；长安的五章自动路线。

### 10.3 新增运行时功能

| 功能 | 说明 |
|---|---|
| 战斗语音事件 | 接力节点和分阵阶段上挂配音和字幕事件，在节点进入、蓄力、命中等时刻触发。同时只播一条，优先级高的新事件打断旧的。播放时压低音乐 |
| 飞剑弹道 | 引擎绘制的 3 帧弹道，起点固定在画面右下方，终点是输入点。判定不等弹道 |
| 打空水花 | 按落点绘制水花贴图，替代长安的符灰 |
| 移动镜头的区域追踪 | 列车车顶的分阵，每帧多边形由追踪生成。要验证高速运动下的区域准确度和早、中、晚命中 |

其余机制（扫描现形、拦截、护盾、解救、顺序、辨真、剧情一剑）都有长安的现成实现，只换素材和数据。

### 10.4 Android 与性能

- 沿用长安的 Android 网页客户端、960 × 540 视频和离线帧页兜底。
- 雨夜的细密雨丝在低码率下容易变成色块。960 × 540 档单独检查画质，必要时提高码率，或在该档减弱雨量。
- 长安实测 PSS 434–500 MiB，高于原定的 300MB。本作视频总量约为长安的六到七成，目标是不超过 400 MiB，M4 实测。

## 11. 生产管线

### 11.1 剧情

按章写分镜（景别、机位、人物、动作、台词、时长）→ 每个镜头的首帧关键帧（ChatGPT，以定妆照和场景母版为参考）→ TTS 配音 → H3 生成，每个镜头 3 个候选 → 关键对白做 LatentSync 口型 → 剪辑、调色、混音、字幕。

锁镜前按第 6 节的秒数核对。补拍的镜头必须替换已有镜头，不能只加不减。

### 11.2 战斗

沿用长安方案第 11.2 节：先画状态图，登记每条可达边；场面母版规划 4–6 个出场位置；`threat` 的首尾锚帧和转场的出入锚帧写进生产清单；定稿视频登记哈希、帧数和来源，区域标注与哈希绑定。

### 11.3 敌人设定

每种敌人一张设定图：正面、侧面、蓄力姿势、攻击姿势、击毁后的样子。铁衣卫的白瓷面甲是全片辨识度最高的元素，最先定稿。
