### 1.2 结论与改动

| 问题 | 本作的做法 |
|---|---|
| 剧情膨胀到 58%。补拍的河上追逐、塔顶到宫门和结尾镜头一路累加 | 纯剧情写成硬上限：全片不超过 35%，每章不超过 75 秒（第三章 90 秒）。每章锁镜前按实测秒数核对，超出时删镜头，不靠加战斗来摊薄比例（第 7 节） |
| 对白集中在独立 CG 里 | 能边打边说的对白放进战斗：青萍的提示、老九的传音，都挂在战斗节点上，不占独立剧情时间（第 10.3 节） |
| 接力等待贴着上限 | 设计目标收紧到 1.2–1.5 秒，单条样本最多 1.8 秒 |
| 生成量估算偏离实际很远 | 按各章分镜和可达分支逐个登记视频 ID，候选和返工另算（第 11.6 节） |
| 模型生成了底部文字，需要裁掉 | 世界观禁止画面内可读文字（[世界观 §10.4](LINYUAN_WORLD.md#104-禁区)），提示词统一加负面词 |
| 实机始终没测 | 实机验证排进里程碑，需求方提供设备（第 13、15 节） |
| 准星、受击和打击感很差：全部是 1 像素的线和小方块，没有震屏，各种事件的效果几乎相同 | 重新设计整套反馈，见 [反馈与打击感设计](LINYUAN_FEEDBACK.md) |

## 3. 游戏概念

一句话：在山水之间御剑破阵，从九曲渡一路打上天机峰。

体验目标：

1. **美**：每一帧都像能截图当壁纸。阳光穿过竹海，玄武在江上涉水，满月照着云海。
2. **帅**：每一剑射出去都有弹道、有声音、有碎裂。琥珀罐被打飞，鬃甲崩落，巨兽跪倒在江滩上。
3. **快**：约十分钟的流程里不冷场。战斗段里连续不可操作的画面不超过 2 秒，剧情段尽量短。
4. **燃**：江湖人被机关兽围攻，主角一路往上打；了尘舍身稳住玄武、青萍主动递出的最后一剑是两个高潮。
5. **暖**：中秋夜，满月下的面摊，一碗面。

和长安的区别：

| 长安 | 临渊 |
|---|---|
| 夜景为主 | 午后、月夜、云上满月，整体明亮 |
| 镜头基本锁定 | 第二章有玄武背上的移动镜头 |
| 保护百姓 | 解救被控制的人：只打天机接口，不打人 |
| 镜子辨真 | 雨中辨真：真身溅起雨花，幻影被雨穿透 |
| 无 | 借势：射断藤索、竹架，让竹排或巨石砸倒机关兽 |
| 妖怪 | 机关瑞兽，弱点是可以被打飞的琥珀罐 |
| 伤感结局 | 温暖结局 |

## 5. 玩法

### 5.1 核心循环

```
剧情（短）→ 战斗（接力）→ 剧情一剑 / 短过场 → 战斗 → Boss → 剧情（转往下一章或进入尾声）
```

- 剧情按段跳过。
- 战斗段里不插入超过 2 秒的不可操作画面。
- 剧情信息尽量放进战斗里的语音事件。

### 5.2 操作

| 动作 | 鼠标 | TVGun | 触屏 | 手柄 |
|---|---|---|---|---|
| 瞄准 | 移动鼠标 | 已校准的枪口 | 触点落点 | 左摇杆移动准星 |
| 出剑 | 左键 | 扳机 | 点画面 | A 或 RT |
| 收剑 | 右键或 R | 向框外射击，或 RELOAD | 右下角收剑键 | X |
| 万剑归宗 | 中键 | SPECIAL | 右下角大招键 | Y |
| 跳过纯剧情 | 空格 | 剧情中 START | 点跳过 | 剧情中 START |
| 暂停／恢复 | Esc | 战斗或剧情一剑中 START；失锁自动暂停 | 系统返回 | 战斗或剧情一剑中 START |

START 在暂停菜单内优先恢复。失锁后先重新取得有效瞄准；仍锁定时的框外扳机才算收剑。跳过剧情只前进到下个交互入口，跳过后的第一个扳机不能穿透到新窗口。

### 5.3 剑匣

- 一匣 8 柄。竹海普通难度的主动收剑耗时 0.16 秒加每柄 0.055 秒，直接击中琥珀弱点返还当柄飞剑。
- 判定使用当前显示帧。剑体沿弧线掠入落点，拖尾与斩痕按墙钟衰减。
- 每次独立扳机输入至多消耗一柄；空匣、收剑中和已封闭的窗口不消耗。顿帧内冻结攻击窗口，重复扳机不能对同一命中帧再次结算。换匣可提前，章节内跨段保留余剑。
- 剧情一剑使用独立的一次出手机会，空匣也能完成。它只结算剧情分支和固定奖励，不消耗普通弹药，不参与剑意充能或普通出剑数量。

### 5.4 万剑归宗

| 项 | 规则 |
|---|---|
| 充能 | 有效命中 +1 格，按难度满 15 / 20 / 25 格，最多存一次 |
| 扣减 | 有效窗口内打空 −2 格；受伤清零 |
| 释放 | 小怪击毁，精英扣 2 点。饕餮仅在口中核心已暴露时开放专用打击分支，一次扣 2 点、清槽，按剩余耐久进入已有的受击或终结镜头；每次释放只结算一次 |
| 限制 | 纯转场、保护对象、拦截、解救、借势和剧情一剑期间锁定；锁定时按键保留满槽 |
| 第 3 章心剑 | 青萍回到匣边后出现独立的心剑提示。按普通出剑键释放，保留此前的剑意值 |

### 5.5 敌人

设计原则：

- 可击毁的单位全部是机关兽。活人身上的天机器件单独标区，镜头让接口与脸、手错开。
- 所有机关兽共用一套设计语言（[世界观 §10.2](LINYUAN_WORLD.md#102-设计语言)）：米白陶瓷甲、深石墨框架、黑色肌肉纤维。靠动物轮廓区分种类，靠琥珀色部件标出弱点，靠眼睛颜色表示状态。
- 轮廓优先，块面要大。不做细腿细杆，弱点部件在 960 × 540 下也要一眼能找到。
- 现身、蓄力、攻击抵达各自标帧，让玩家先找到目标，再读懂威胁；教学首敌可等待。

**小怪**（一剑击毁，接力出现）

| 敌人 | 章 | 行为 | 击毁 |
|---|---|---|---|
| 毕方（鹤形飞行机关） | 1、2 | 从屋顶或天空飞来，悬停时眼睛变红，然后俯冲扑击，或从翼下射出火镖 | 燃料囊炸开，翼片散落，打着旋坠地 |
| 狻猊（狮形机关兽） | 1–3 | 从遮挡物后跃出，伏低张开鬃甲，然后扑向镜头 | 肩罐被打飞，鬃甲崩落，侧身倒下冒烟 |
| 隐狐（隐身狐形机关） | 1、3 | 只有落叶、水汽和光斑勾出的轮廓，青萍扫描后才现形 | 隐身甲片碎散，倒地 |

### 5.7 判定

先按输入时间找到已呈现的视频帧，逆算该帧的画面偏移，再查可见区域。同一扳机只取一个结果。天机接口、燃料囊和天机链按实际可见部分标区，人体保护区扣去这些露出的器件；人体遮住器件时按人体判。先查直接落点，再对空白窄带做辅助瞄准，禁止跨过人体吸附。扫描前和雨中辨真时，准星、描边、辅助吸附及提示音均不得泄露答案。

## 8. 打击感规格

完整规格见 [反馈与打击感设计](LINYUAN_FEEDBACK.md)，包括准星、目标与威胁指示、敌人受击、玩家受击、声音、震屏、万剑归宗和验收方法。要点：

- 长安的反馈全部是 1 像素的线和 3 × 3 的方块，命中、净化、打空几乎是同一个效果，没有震屏，受击只是上下两条红边。本作重做整套反馈。
- 按 L0–L4 五个强度等级统一分配顿帧、震屏、闪光、粒子和声音层数。
- 准星加粗描边，带指向状态和弹药刻度；命中点有命中标记和得分飘字。
- 敌人受击：剑痕弹道、剪影闪白、按材质的火花和碎片、二段闪、冲击环。琥珀罐被打飞是本作最重要的一类反馈，视频里拍出罐体飞出，引擎同步叠加琥珀色的爆闪和碎片。
- 玩家受击：顿帧、方向光、震屏、色差、按攻击类型的屏幕叠层、生命图标碎裂、全局声音闷压。误伤用冰白色，和受击完全区分。
- 仍用 SDL_Renderer，加贴图、加法和乘法混合、`SDL_RenderGeometry` 实现，不必先换 GL。
- 画面明亮，反馈的闪光和描边要在亮背景上也看得清：准星和标记一律带深色描边，闪白改成按目标剪影提亮，不做全屏白闪。

## 9. 美术

风格规则、公共提示词段和已选参考图见 [美术风格](LINYUAN_ART_HORIZON.md)，设定层面的规定见 [世界观 §10](LINYUAN_WORLD.md#10-视觉圣经)。生产上的补充：

- **满画面里的可读性。** 测试图细节很多，花草、藤蔓、远山和光柱铺满画面。战斗母版要给中景留出安静的空地，敌人在空地里出场；前景只在画面边缘放遮挡。按 MVP 第 1.3 节在 960 × 540 无 HUD 画面上复看。
- **暖光不靠近弱点。** 琥珀罐和阳光、灯笼、夕照都是暖色。太阳不放在可打区域附近，灯笼不挂在敌人出场位旁边；琥珀罐靠饱和的橙色、圆柱形状和金属箍与暖光区分。
- **植被在接缝处的闪烁。** 竹叶、草和花在视频里每帧都在动，波次与击毁片接回母版时容易看出跳变。战斗母版用微风，减少飘落物，交叉淡化只放在无交互接缝（M0 验证）。
- **风格化写实的稳定。** 测试图是游戏过场的质感。H3 生成视频时可能漂向真人实拍或卡通，每条视频都以关键帧为首帧，并在提示词里写明质感（M0-B 验证）。
- **光身青萍。** 在阳光下也要半透明、看得见背后的景物。风险是视频模型把她画成实体，M0-B 验证。
- **人脸镜头。** 剧情以中景和全景为主，脸部大特写全片不超过 10 个。
- **一致性。** 沿用长安的五层控制：镜头设计、定妆照加场景编辑首帧、ReferenceToVideo 带定妆照、必要时训练角色 LoRA、人工对照。机关兽另以设定图为参考，四种小怪和精英的甲片、接缝和眼睛必须像同一家工厂的产品。
- **每章一种光。** 第一章是午后到黄昏的暖金阳光，第二章是月光加灯笼和火光的蓝金夜色，第三章是云海上的满月和天机环的冷光。章与章之间画质漂移不累积。
- **天机环。** 环在每章的远景里出现，表示离子时还有多久。它只出现在分镜指定的镜头里，不要每张图都有；红光合拢的程度按章节递进。

### 10.2 播放器参数化

| 功能 | 说明 |
|---|---|
| 战斗语音事件 | 接力节点和分阵阶段上挂配音和字幕事件，在节点进入、蓄力、命中等时刻触发。保护／拦截提示优先，其次是教学，再次是闲话。提示先于可射窗口，对应图形同帧可读；跨切镜保持自然时长，高优先级语音可抢占，离场与续关清理 |
| 飞剑与剑匣闭环 | 8 槽剑匣口沿二次贝塞尔弧线射出 160 毫秒立体飞剑（五段式剑体与加法剑气拖尾，抵达落点迸开十字斜劈斩痕）。无辅助直击琥珀弱点在 100 毫秒顿帧后自动沿弧线飞回匣口；主动收剑按已出剑数动态耗时（`0.16 + 0.055 × 已出剑数` 秒）召回全部留场飞剑并触发归匣剑光 |
| 弱点、重甲与危急红芒 | 支持多连通域弱点掩码聚类（双弱点环）、重甲差异伤害（`weak_damage`，白甲两剑破甲／弱点一剑秒杀）、隐狐现形前抢射落空（`allow_early_miss`）以及攻击抵达前最后 0.5 秒的逐帧危急红芒轨迹（`threat_glows.json`） |
| 打空与碎片反馈 | 敌人节点与片段通过数据驱动字段 `material`、`tier`、`attack` 指定受击旋转三角碎片（陶瓷甲、翼片、藤索、晶针）与受击叠层；固定机位打空按 64 × 36 材质格绘制水花、石面火星、尘土、竹叶 |
| 移动镜头的区域追踪 | 玄武背甲边缘的分阵，每帧多边形由追踪生成。要验证游动中的区域准确度和早、中、晚命中 |

沿用长安的分阵、保护区、拦截、分支回答及 `story_shot`。临渊还需让街战与分阵共用显示帧变换、反馈和重新开窗规则，避免长安分阵约 150 毫秒的连点门槛与临渊顿帧重复叠加。饕餮以已暴露的口中核心为可打区域，复用分阵的扣耐久路径；测试剩余 1、2、3 点耐久时释放，核对清槽、扣血和去向。另验两种幻影击碎顺序、剧情一剑空匣／超时、保护区边缘及章节切换的弹量。

剧情一剑的三档窗口按现实秒数配置。以毕方攫住云姨为例，在 24 fps 素材上以半速展示，普通的 2 秒窗口占 24 个源帧。当前分阵固定使用 72／48／29 个源帧，须让两端按素材帧率和实际速度换算，并逐档检查截止帧仍在可见区域内。PC 另需接入手柄事件及摇杆瞄准，在菜单、战斗和分阵各验一次死区、出剑与 START。

### 10.4 Android 与性能

- 沿用长安的 Android 网页客户端、960 × 540 视频和离线帧页兜底。
- 竹叶、草地和花丛的细节在低码率下容易糊成色块或闪烁。960 × 540 档单独检查画质，必要时提高码率，或在该档的母版上减少细碎植被。
- 长安模拟器抽样峰值 PSS 为 434–500 MiB。临渊的预算是应用及可识别 WebView 渲染进程合计峰值 ≤400 MiB。以最长转场、L4 叠层和切换离线帧页时的实测为准。超预算先减少预取片段、及时释放上一镜头的解码资源，再降低粒子档位。包大小单列。

第一章战斗的波次与击毁片均带完整场景，场面底片只供入场和接缝。桌面沿用整帧 `encounter` 路径；长安 Android 街战默认合成独立街景和前景帧页。临渊需为整帧战斗导出视频、同源帧页与判定掩码，并在 M1 的第一章战斗上跑通早、中、晚命中及解码失败后原地续打（MVP 不含 Android）。长安的分层素材继续走原路径。

## 11. 生产管线

### 11.1 剧情

按章写分镜（景别、机位、人物、动作、台词、时长）→ 每个镜头的首帧关键帧（ChatGPT，以定妆照和场景母版为参考）→ TTS 配音并试排对白时长 → H3 按 §11.6 的候选预算生成 → 关键对白做 LatentSync 口型 → 剪辑、调色、混音、字幕。

锁镜前按第 6 节的秒数核对。补拍的镜头必须替换已有镜头，不能只加不减。

### 11.2 战斗

沿用长安方案第 11.2 节：先画状态图，登记每条可达边；场面母版规划 4–6 个出场位置；`threat` 的首尾锚帧和转场的出入锚帧写进生产清单；定稿视频登记哈希、帧数和来源，区域标注与哈希绑定。

### 11.3 敌人设定

每种敌人一张四格设定图：平静、侧面、敌对攻击、击毁，背景用该敌人实际出场的场景和光照，不用棚拍。Boss 单列各阶段。狻猊出场最多，最先定稿，其余机关兽以它为材质和接缝的基准。

### 11.4 声音

## 14. 主要风险

| # | 风险 | 缓解 |
|---|---|---|
| 1 | 剧情再次膨胀 | 第 7 节的硬上限；补拍必须替换已有镜头 |
| 2 | 玄武背上的移动镜头区域追踪不准，或接力切换时跳位 | M0-D 先验证；不行就改为寺院梯台上的固定机位，只让远处江岸移动 |
| 3 | 画面太满，目标被花草、光柱和远景淹没 | 战斗母版给中景留空地；按 MVP 第 1.3 节缩图复看；暖光远离弱点 |
| 4 | 植被和光斑在接缝处闪烁、跳变 | 战斗母版用微风、少飘落物；交叉淡化最多 2 帧且仅放在无交互接缝；对照空景检查 |
| 5 | H3 把风格化写实漂成真人实拍或卡通，或各片之间质感不一 | 每条视频以关键帧作首帧，提示词写明质感；M0-B 先做三段动态试片 |
| 6 | 机关兽被画成真动物或带血 | 设定里强调外露的框架、肌肉纤维和陶瓷甲；负面提示词；人工把关 |
| 7 | 光身青萍在阳光下被画成实体，或忽隐忽现 | M0-B 验证；退路是后期统一加光身调色和透明度 |
| 8 | 和现有游戏太像 | 提示词里不写其他游戏名，原型一律取《山海经》和中国传统器物；机关兽的轮廓以中国瑞兽为准 |
| 9 | 画面里出现乱码汉字 | 世界观禁区；旗帜、匾额、石碑无字；人工把关 |
| 10 | 谢无咎的 12 柄剑在画面里太小，亮起顺序看不清 | 剑阵在关键帧里铺满画面上半部；亮起的剑叠引擎光环 |
| 11 | 播放器参数化破坏长安和西部 | MVP 先接最小世界开关，完整清单在 M0-E 接入；两次都用修改后构建的播放器跑旧作回归 |
| 12 | 实机延迟和准度 | M4 排实机，需求方提供设备 |
