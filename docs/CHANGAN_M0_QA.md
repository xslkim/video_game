# 《长安灯妖录》三节点试玩验收

本页记录首版 Windows 包。采用动态街景的新版、两种 H3 样片和分支边界回放见[动态街景试玩验收](CHANGAN_MARKET_QA.md)。

2026-11-23。T00–T04 交付就绪。Windows x64 发布包通过规则、素材和发布包自动回放验收，镜头连贯性与操作手感待需求方试玩确认。

## 启动与试玩

解压整个 `dist/Changan-Windows-x64.zip`，运行 `Changan/Changan.exe`，按 Enter 开始。鼠标左键施符，右键或 R 换匣，Esc 暂停，F11 全屏。普通路线从 3 条生命、8 支符箭起步。

先等左侧灯笼妖横移再试着命中。第二段可让右侧青火先发射，击散青火球，再净化回到原位的青火。最后给巷心狐火妖三次有效命中。通关后可从标题重开，比较同一动作在不同帧的切换。键位、构建与回放命令见[试玩说明](PLAY_CHANGAN_M0.md)。

## 独立发布包回放

| 路线 | 时长 | 关键结果 |
|---|---:|---|
| 正常 | 10.97 秒 | 灯笼妖第 21 帧命中，5 发全部命中，3 命通关 |
| 提前 | 8.10 秒 | 灯笼妖第 2 帧命中。转场第 3 帧乱按保持 7 发。随后在两段转场尾部直接命中青火和狐火妖 |
| 晚命中 | 11.75 秒 | 灯笼妖第 40 帧命中，走单独的晚段净化入口，3 命通关 |
| 拦截首帧 | 13.39 秒 | 青火第 37 帧发射，生命仍为 3。第 38 帧拦截成功，本轮无伤 |
| 拦截末帧 | 14.86 秒 | 第 67 帧拦截成功，3 命通关 |
| 抵达时点击 | 14.55 秒 | 第 68 帧输入被忽略，火球抵达只扣 1 命，余 2 命通关 |
| 雷符硬直、雷符终结 | 9.69 / 9.70 秒 | 测试回放以满槽开局。狐火剩 3 点时减到 1 点并进入硬直，剩 2 点时直接净化，两次都耗尽雷符槽 |
| 失败、暂停、换匣与重玩 | 30.22 秒 | 首轮耗尽 3 命。重开后暂停恢复，从 7 发换至 8 发。通关返回标题释放解码对象，再重开通关。重复点击在精英顿帧期间未重复结算 |

连续游玩时，从上一目标有效命中到下一目标的有效帧提交，实测为 **1.37–1.80 秒**。自然路线的两次等待是 **1.77 秒和 1.57 秒**。带暂停的回放单列。JSON 分别记录输入、首次可击帧提交、下一次有效射击，反应时间为脚本结果。

测试机为 Core Ultra 7 265K 和 RTX 5090。回放从注入的 SDL 事件记录到渲染提交返回，反馈延迟 P50 / P95 为 33.34 / 33.96 毫秒（56 次），分支首帧 166.48 / 167.01 毫秒（50 次，含顿帧）。所有命中切片在切换时都可从预热槽取得，预热可发生于顿帧中。真实显示设备的光电延迟另测。

九次回放中解码对象峰值为 2，进程工作集最大 104.36 MiB，视频包和解码音频的估算驻留峰值 7.76 MiB。单张 720p YUV420 纹理的像素数据为 1.32 MiB，实际 GPU 分配随驱动而异。此小样只有朱雀大街，跨场景资源释放可在下一原型用两处场景复测。
