# 长安灯妖录 · 五章巡灯

将 Windows 压缩包完整解压，双击同一目录中的 `Changan.exe`。视频、地图、中文对白、环境声和配乐均随包提供。标题处可用鼠标选择难度并开始，也可按 1、2、3 选择简单、普通、困难，再按 Enter。M 调配乐，F 调音效，G 调对白，V 切换字幕。

鼠标左键施符，右键或 R 更换八箭符匣。雷符蓄满后用鼠标中键释放。剧情里的关键一箭使用普通射击。空格跳过当前剧情段落，Esc 暂停。每段结束自动存档，下次启动可从标题选择「继续巡灯」。五章结束后可查看各章评级和总成绩。

| 章 | 游玩提示 |
| --- | --- |
| 朱雀大街 | 灯贩经过时收弩，牌楼上瞄准绳结救人。巨鲤吐青火时可先拦截。 |
| 西市幻术坊 | 观察伞面和盾牌打开的时机。萤火绕着真正的阿萤，两侧假镜都可以先打。 |
| 曲江池 | 在移动的夜船上追踪河灯。九首龙舟要按亮灯顺序施符。 |
| 大雁塔 | 先点亮经卷旁的灯，让墨鸦现形。塔顶的灯链会指向宫城。 |
| 太极宫 | 解救被附身的宫人，逐盏熄灭护灯。最后用普通射击键回应阿萤。 |

**Windows 光枪。** 以 `Changan.exe --tvgun` 启动。在另一部手机安装随附的 `TVGun.apk`，选择 UDP 游戏模式，将手机和显示端接入同一局域网。摄像头需要看见整个白框。START 开始，扳机施符，RELOAD 换匣，SPECIAL 释放蓄满的雷符。失锁会暂停游戏，重新对准白框后按 START 继续。

**Android 手机与电视。** 把 `Changan.apk` 安装到要显示游戏的设备。触屏点画面施符，右下角有换匣和雷符按钮。标题中的「画质」可在标准和省电之间切换。两档共用相同的视频时间轴和命中区域。电视可接游戏手柄，摇杆移动准星，A 或 RT 施符，X 换匣，Y 放雷符，START 开始或暂停。用另一部手机作光枪时，在显示端标题启用 TVGun。

**存档与评分。** 每段结束后保存。中途关闭会从当前段开头继续，已经完成的章节成绩会保留。续关沿用存档难度，选择「重新开始」可采用新选的难度。章节末显示得分、命中率、最高连击、受伤次数和净化数，片尾可查看总评。
