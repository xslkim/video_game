### 0.4 波次的时间结构

普通敌人波次按下表规划。扫描、货郎、竹排、精英和 Boss 单独标窗。表中帧号从 0 开始，使用 24fps 的成片时间轴；定稿后登记实际可见帧和视频哈希。

| 帧 | 内容 |
|---|---|
| 0 | 场面母版，没有敌人 |
| 1–10 | 敌人从遮挡物后现身，第 10 帧前必须清楚可见 |
| 10 起 | 可命中 |
| 28、42、56 附近 | 从可打姿态中取早、中、晚三个击毁入口。判定使用玩家出剑时实际显示的帧，分支用姿态、位置最接近的入口。隐狐的三个入口都在现形后 |
| 40 左右 | 蓄力开始（狻猊伏低张鬃、毕方眼睛变红收翼），引擎开始画预警括号 |
| 66 左右 | 攻击抵达（扣命帧），按实际成片标注 |
| 67–98 | 攻击后退回遮挡物，第 98 帧回到场面母版 |

普通击毁的等待预算为 70 毫秒顿帧 + 最多 22/24 秒击毁片 + 约 10/24 秒现身，约 1.40 秒。验收从命中的显示帧到下一目标首次可打的显示帧计墙钟，含切片开销，目标 1.2–1.5 秒，单条最多 1.8 秒。击毁动作应在可用帧内恢复母版，才可裁去静止尾段。场面底片用于入场与接缝。首波直接播放带场景的整帧成片；命中掩码单独读取。

所有敌人都从遮挡物后现身，被击毁后倒向遮挡物后方、坠进水里或摔进草丛，这样击毁片才能回到干净的场面母版。

- 窗口：c1_10_talon 先用约 3 秒交代险情，燃料囊与云姨的头和手之间留出天空作背景。简单、普通、困难的可操作墙钟分别为 3 / 2 / 1.2 秒；24fps 素材在 0.5 倍慢放时普通 2 秒窗口占 24 个源帧（`72..95` 帧）。慢放开启的前 0.5 秒（`72..77` 帧）由毕方掠过的翼羽半遮燃料囊，后 1.5 秒（`78..95` 帧）燃料囊完全暴露，既保留稳定的悬停姿态供切入分支，也塑造“看准破绽再出剑”的节奏。
- 普通出剑键触发独立剧情一剑，弹匣余量跨段保留。命中燃料囊走 hit 得 1000 分；打空、超时走 miss 得 0 分。命中云姨或她的机关前臂按同章误伤规则结算，存活走 miss，阵亡按续关规则处理。燃料囊与人身的遮挡帧关闭目标或裁掉，辅助瞄准不得跨人身吸到燃料囊。只在实际扣扳机时由引擎画剑痕。
- 两条结果片共用同一尾锚，铁勺落在脚边。命中燃料囊、打空或超时接道谢近景，误伤接嗔怪近景，各自用所选语音驱动口型。
- 普通单次路线最长约 5 + 3 + 3 = 11 秒，命中与失手各占一个结果镜头。提前出剑直接进分支，配音按可用秒数试听。
