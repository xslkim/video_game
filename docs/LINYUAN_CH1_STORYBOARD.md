| Boss 段落 | 47–119 帧 | 按状态锚帧 | 按本文 |

### 0.4 波次的时间结构

每条战斗波次片都按同一结构生成，便于接力和标注：

| 帧 | 内容 |
|---|---|
| 0 | 场面母版，没有敌人 |
| 1–10 | 敌人从遮挡物后现身，第 10 帧前必须清楚可见 |
| 10 起 | 可命中 |
| 28、42、56 | 击毁锚帧：从这三帧中最近的一帧切进击毁片（长安 A1 的做法） |
| 40 左右 | 蓄力开始，引擎开始画预警括号 |
| 66 左右 | 攻击抵达（扣命帧），按实际成片标注 |
| 67–98 | 攻击后退回遮挡物，第 98 帧回到场面母版 |

接力等待 = 击毁片可用长度（约 0.9 秒）+ 下一波次的现身时间（约 0.4 秒），约 1.3 秒，落在策划案第 7 节 1.2–1.5 秒的目标内。

所有敌人都从遮挡物后现身，被击毁后倒向遮挡物后方、坠进水里或炸散，这样击毁片才能回到干净的场面母版。
