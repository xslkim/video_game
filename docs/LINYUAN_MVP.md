## 0. 目的

第一章批量制作之前，先做一段约 1 分钟的可玩切片，回答两个问题：

1. **玩法**：玩家能否在明亮、细节很多的画面里找到目标、读懂威胁、知道这一剑打出了什么结果，并愿意自己再打一局？接力时间、判定和反馈帮助定位原因。
2. **美术**：面摊的烟火气、青萍的光身、竹海里的机关兽与飞剑，能否让人从画面和动作认出同一个武侠山水世界？这套风格化写实的画面能否在 H3 视频里保持住，经得起运动、接缝和缩图？

沿用第一章的成片 ID。分两次作决定：先用面摊与竹海的四个视频在 Windows 上看风格、试出剑和接力，再制作完整一分钟切片，交给首次接触的玩家。使用临时音效、占位片或长安素材得到的结果注明用途。MVP 的结论适用于第一章的午后光照和鼠标操作。

MVP 与策划案里程碑的关系：

| 里程碑 | MVP 中的处理 |
|---|---|
| M0-A 三节点小样 | 扩成竹海整条链（10 节点） |
| M0-B 美术验证 | 先锁首批 9 张参考图，做 3 组动态试片（4 个视频 ID）；通过后补齐 §2.4 的 20 张图。青萍的跨镜动态一致性留给完整 M0-B |
| M0-C 声音验证 | 只做 MVP 用到的 10 句台词和反馈音效；谢无咎的台词和完整配乐留到 M0-C |
| M0-D 移动镜头 | 不在 MVP 范围 |
| Android 整帧战斗 | 不在 MVP 范围，移到 M1 |
| M0-E 播放器参数化 | 只做最小的世界开关；完整的世界清单留到 M0-E |

## 1. 要回答的问题

### 1.1 玩法

| # | 问题 | 怎么验证 | 通过标准 | 不通过时 |
|---|---|---|---|---|
| G1 | 接力够快吗 | 自动回放量系统等待，真人试玩记目标是否跟得上 | 普通接力目标 1.2–1.5 秒，单条最多 1.8 秒；扫描首秀、精英转段、借势和重试单列，连续不可操作均 ≤2 秒。竹海 40–50 秒是普通参考路线预算，熟练玩家提前命中可缩短 | 按超时样本区分顿帧、击毁尾段、解码和下一目标前摇，只改对应一处后重测 |
| G2 | 打起来有没有分量，能否分辨打出了什么结果？ | 同输入的新旧反馈对照、静音辨形、盲听辨声；另测本机输入到首次反馈提交 | 需求方实玩认可新版；命中未击毁、击毁、打空、拦截、受击、误伤这 6 类结果逐类统计，静音、盲听各至少三分之二的新手能辨对。记录 P50、P95、样本数与刷新率，目标 P50 ≤一个刷新周期 | 分别修轮廓、声音或提交延迟；用同一事件复测 |
| G3 | 玩家看懂第一次提示了吗 | 逐人记录首次到达、首窗结果及事后理由 | 首次遇到隐狐时能等到现形再命中；飞针和藤索分别在首窗命中；毕方攫住云姨时首窗击中燃料囊。四项各至少半数首见者成功；因燃料囊被翅膀或云姨遮住而误伤须改镜头。分别列打空、打人、超时和扫描前抢射 | 先回看当时的画面与喊话，再决定改提示、构图或窗口 |
| G4 | 普通难度能学会吗 | 记录首轮无续关通关、死亡位置，以及空匣到首次完成收剑的时间 | 超过半数新手首轮无续关通关，并能自行收剑。初始 3 命，第 3 次扣命进入续关；无伤通关有效。熟练回放须能无伤完成 | 先定位卡在输入、目标辨认还是反应时间，再调相应环节 |
| G5 | 这段玩法值得再打一遍吗 | 结果页同时提供"再打一局"和"结束"；先记自愿选择，再安排对照测试 | 至少三分之二的新手主动重玩。另记想看后续剧情的人数及理由 | 根据放下鼠标的时刻和理由，选一个最影响重玩的环节复测 |

### 1.2 美术

| # | 问题 | 怎么验证 | 通过标准 | 不通过时 |
|---|---|---|---|---|
| A1 | 玩家看到了怎样的世界？ | 首玩后给出无 HUD 的面摊与竹海画面，请玩家用自己的话说出地点、时代感、武器及判断依据，再分别打喜好分 | 需求方认可两处属于同一美术方向；至少三分之二的新手能各指出一个武侠线索和一个机关线索，并说清出剑或收剑的可见动作。960 × 540 实际缩放回放里仍能找到目标 | 若只说得出"好看的风景"，先改剑匣、剑痕起点或机关兽的出场动作，再用同一机位复评 |
| A2 | 机关兽像机器、又像活的吗 | 先看狻猊的出场、扑击和肩罐被打飞，再看竹海四类敌人的登场和击毁 | 能辨认机械结构、材质和断电倒地；动作像动物而不像机械臂；琥珀罐被打飞的瞬间看得清；成片中没有血或真动物受伤的画面 | 先改对应敌人的外形或动作 |
| A3 | 人物好看、一致吗 | 面摊动态与布棚下静帧并排认陆沉；面摊与近景认云姨；正常速度看青萍身后的面摊是否始终可见 | 换机位仍能认出人物，需求方认可定妆。面摊同一镜内脸、义肢侧别和青萍的透明度稳定；本次只有一个青萍动态镜头 | 先修参考图、机位或选片；同一人物仍漂移再评估 LoRA |
| A4 | 画面有字或乱码吗 | 检查全部入选帧及成片 | 旗帜、布棚、石碑只见纹样，可读文字和乱码均退件。字幕和地名字卡由引擎绘制 | 重选或重出问题镜头 |
| A5 | 接缝及分支自然吗 | 五条普通波次各验早、中、晚击毁；藤索验两个切点；飞针验早／晚拦截和抵达；另验燃料囊两结果回共同尾锚 | 正常速度无明显跳位，逐帧复核动作方向、弱点位置及道具状态。拦截后回屋顶，竹排落下后停在竹排已落的母版 | 先改入口或缩短尾段；仍穿帮再补对应状态 |
| A6 | 风格在视频里稳吗 | 把无 HUD 的竹海空景、敌人出场和击毁接回空景连播，按 §1.3 复看；面摊镜头与其首帧关键帧对比 | 竹叶、花草和光柱在接缝处没有明显跳动；敌人入场时背景没有整幅跳亮或变色；视频保持关键帧的风格化写实，不漂向真人实拍或卡通 | 用空景核回曝光与光照，修正出场位置、植被密度或剪点；质感漂移时改提示词的质感描述后重出 |

### 1.3 满画面里的可读性

1. 先单看竹海空景 PL_BAMBOO，由需求方确认光柱、空地和遮挡物的布局。再将同机位空景与敌人入场、蓄力、弱点开放的画面来回切换，隐藏 HUD、准星和区域标注。观察同一块石祠、大青苔石和溪水，三处应保留母版的亮度和颜色。藤索击断后用 PL_BAMBOO_X 比对，允许竹排及坡上的局部随之变化。
2. 在同一台 Windows 显示器上用固定 SDR 图像模式、相同室内照明，关闭自动亮度。将片段缩至 960 × 540，以 1:1 像素正常速度播放。先用日常亮度，再把显示器背光设为约日常读数的一半（如 60/100 调到 30/100）。记录机型、模式、两次实际刻度和片段 ID；两次使用同一份视频及调色。
3. 两档均请评审者指出伏低张鬃的狻猊、收翼俯冲的毕方和屋顶的鳞扇，分清飞针仍在空中与飞针结束后圆芯可打的时刻。云姨镜头另指燃料囊与她的头和手之间的空隙。隐狐在扫描前仅露落叶和光斑，扫描后须看清前冲动作；竹排下出现两只狻猊时，应能指出上方可打的藤索结。逐项记录看错的动作、落点及帧号。只认出亮点、分不出开闭或看不出前扑时，先调出场位周围的留白、植被密度或机身朝向，在锁定的母版上复测。另查琥珀色弱点有没有和光柱、阳光混在一起。MVP 只记录这台显示器的结果，电视表现和客厅观看距离留到 M4 实机验证。

## 2. 内容范围

### 2.1 试玩流程

| # | 段落 | 来源 | 时长 | 主要验证 |
|---|---|---|---|---|
| 1 | 标题 | 引擎，纯文字 | — | — |
| 2 | 面摊 | c1_04_noodle（分镜 §1） | 5 秒 | 人物、青萍光身、三人同框（A1、A3） |
| 3 | 毕方攫住云姨 | S3 全部（分镜 §3） | 约 11 秒 | 剧情一剑、保护区、误伤、云姨口型（G3、A3） |
| 4 | 转场 | 引擎黑场加地名字卡"九曲渡 · 后山竹海" | 1 秒 | — |
| 5 | 竹海 | S5 全部 10 个节点（分镜 §5） | 约 45 秒 | 接力、扫描、拦截、精英、借势、收剑（G1–G4、A2、A5、A6） |
| 6 | 结果页 | 引擎 | — | 得分、命中率、受伤、用时；开发模式另显示接力等待 |

标题和结果页停留另计。按 5 + 11 + 1 + 45 估算，参考路线约 62 秒。竹海 45 秒含敌人出场、击毁和收剑；燃料囊普通窗口 2 秒。实际能出剑的时间由开放窗口日志计算。

**为什么选竹海。** S5 把扫描、破弱点回剑、飞针拦截与藤索借势放在同一场战斗。S3 只给一次独立剧情剑，起步 3 命。击中燃料囊得 1000 分，打空或超时走云姨自救片；误伤扣 1 命和 100 分，近景改为嗔怪催促，余命带入竹海。S5 以满匣 8 柄开始，是否需要主动收剑取决于落点。首次剑尽提示右键或 R 收剑。

**为什么不做饕餮。** 饕餮要 16 段视频，它的罐箍、拦截和核心机制在鲮鲤身上已有小规模版本。MVP 只用它的设定图看造型。

**操作与结算。** 左键出剑，右键或 R 主动收回已射出的剑。普通难度收剑时间为 0.16 秒起手加每柄 0.055 秒，召回 2 柄为 0.27 秒，8 柄为 0.60 秒。精准命中可打琥珀部件时当次飞剑自回。隐狐首秀和竹丛隐狐现形前抢射按场景打空并耗剑，现场只出材质反馈。Esc 暂停；空格跳过纯剧情。一次按下最多结算一剑，切镜或离开菜单需松键再出剑。普通波抵达只扣一命，存活重播当前节点；阵亡可续关或结束。

| 结算项 | MVP 规则 |
|---|---|
| 救云姨 | 独立剧情剑命中 +1000，打空或超时 0，误伤 −100 并扣 1 命。分数记录允许为负。打空、超时、误伤分别记事件，共用自救片。四种结果均单列于普通出剑统计之外 |
| 竹海普通命中 | 每次实际发射计一次出剑。直接命中隐狐琥珀核、毕方燃料囊、狻猊肩罐或鲮鲤圆芯返还当柄。机身、飞针、藤索、打空均消耗一柄。普通小怪一击击毁，第 8 波装甲狻猊白甲两击、肩罐一击。精准弱点有独立爆裂声、100 毫秒顿帧和 6 像素震屏 |
| 竹海计分 | 普通小怪及精英终击沿用长安的击毁倍率：反应秒数从本次窗口开放起算，反应倍率为 `1 + 0.5 × max(0, 1 − 秒数 / 1.8)`，连击倍率为 `min(3, 1 + 0.05 × 本击后连击数)`。击毁基础分（含弱点奖励）乘两项并四舍五入。打空或扣命清连击。击中有效目标、首个成功拦截及藤索各加一次连击 |
| 重复发针与借势 | 鲮鲤每个耐久阶段的首次成功拦截奖励 150 分。露芯超时导致的同阶段重拦仍计实际命中，奖励只领一次。藤索击断固定 400 分、两只击毁、一次推进 |
| 结果页 | 命中率为竹海有效命中数除以实际发射数（含回剑命中），无发射显示“—”。故事剑单列。记录实际扣命与暂停、续关菜单以外的经过时间 |
| 续关 | S5 以 3 命 8 剑从节点 1 重来。保留 S3 的分数和扣命记录，撤回失败那次 S5 的分数、命中、出剑、连击、击毁与伤害。用时含失败尝试，原始日志保留每次死亡、续关和退出，首轮无续关指标据此统计 |

**无伤核对。** 1–8 波各直击弱点一剑，9 波两次拦针加两次刺芯，10 波一剑斩藤索，共 13/13 命中、11 只击毁、2 次拦截。全精确弱点路线可全程免手动收剑；打白甲路线另验余剑、部分收剑和第 8 波第二次出手。

**鲮鲤露芯。** 拦下一簇飞针才开放圆芯。首剑刺芯后踉跄、合鳞，进入 c1_pangolin_threat 第二轮发射。再拦一簇、再刺芯才击杀。每次露芯保留两秒，超时关芯并重射；漏拦只扣一命，保留精英剩余耐久。暂停冻结窗口。

### 2.2 反馈事件覆盖

| 事件 | MVP 中的来源 |
|---|---|
| L0 打空 | 任意节点 |
| L1 命中未击毁 | 鲮鲤圆芯第一剑 |
| L2 击毁小怪、拦截 | 普通节点；鲮鲤的暴雨梨花 |
| L3 击毁精英 | 鲮鲤圆芯第二剑 |
| 受击：扑咬、撞击、爆炸 | 狻猊和隐狐、毕方、鲮鲤 |
| 误伤 | 燃料囊一剑打中云姨 |
| 剧情一剑 | 毕方攫住云姨 |
| 收剑、剑尽、现身提示、蓄力预警、准星的目标、弱点、保护及空匣状态 | 竹海链与面摊一剑 |

不覆盖的事件：格挡（第一章没有护盾）、解救（第二章）、L4 和万剑归宗（竹海切片关闭剑意充能）。M1 验万剑归宗和 L4，M2 验格挡和香客解救。调试预览无需为本切片专门实现。

### 2.3 不做的内容

- S1 只用面摊一镜；S4 的布棚下镜头和 S6 的饕餮只用静帧。S2、S7 和第二、三章均留在正式章节。
- 万剑归宗、简单和困难难度。只做普通难度，难度参数留好接口。
- 存档、章节结算和总评、标题美术。
- Android、电视和 TVGun 实机、手柄。MVP 只在 Windows 上验证美术和玩法；Android 的整帧战斗和帧页切换在 M1 验证。TVGun 可以在 PC 上用本机 UDP 冒烟一次，不作验收。
- 完整配乐。使用一首临时战斗曲；两版对照使用同一音源和音量。
- 完整的世界清单参数化（见第 3 节 E2）。

| E7 | 对照和记录 | 开发模式复用帧号／掩码查看；用启动选项选择旧／新反馈，同一输入记录可重放两版。真人采集独立于自动输入与录像 | 首玩保留真实鼠标操作；回放能还原命中点和分支。结果页供玩家直接选择重玩或结束 |
| E8 | 试玩包 | `dist/Linyuan-MVP/`，附操作说明，可在仓库外离线启动 | 解压到新目录、从其他工作目录启动并通关 |

每次输入、提示、开窗、分支和反馈提交都带同一单调时钟、节点、显示帧与起因。保留下列三套读数。

- **接力**。普通目标的系统等待取 T_open−T_hit，T_open 是下一目标首个已呈现的可打帧，含顿帧、切片和解码。即使玩家直到受伤都没出剑，也要保留这条开窗记录。另记收剑起止和第一发实际输入，区分玩家等弹与目标迟开；暂停、跨场和重试另列。普通接力报告逐条和中位数，中位目标 1.2–1.5 秒，能看清的更快接力无需补等待，单条上限 1.8 秒。
- **首见机制**。现形、飞针、藤索和燃料囊各记首次提示、首个可打帧、窗前扳机、窗内第一剑及结果；未射记超时或未到达。另记空扣与收剑开始／完成。不从普通接力的 `reaction_ms` 推算这些事件。
- **输入反馈**。用 `feedback_submit_ms` 的口径量有效输入至首帧反馈提交。在固定刷新率下关闭录屏与同步截图写盘，另用同一输入重放录下视听对照。

## 5. 验收与试玩

### 5.1 内部验收

试玩前先自测：

1. 无伤路线从 S3 到结果页：剧情剑单独结算，S5 常规无伤路线（`normal`）共发射 13 柄飞剑并全部命中（含鲮鲤双轮拦针与双轮刺芯），触发 6 次弱点直击回剑与 1 次 2 剑快速收剑（0.27 秒），结束余 3 柄；全弱点路线（`shoulder`）13 剑全中、8 次弱点回剑、全程 0 次手动收剑、结束余 5 柄。E6 的失误路线核对每轮伤害与分支；续关从本战斗段入口以满命满匣重来，撤销失败段得分。
2. 按 §3 的口径报告每个普通接力样本、最慢切点、特殊窗口和 G2 延迟。固定脚本的输入时机写进报告，便于复测；不为凑时长延迟开窗。
3. 反馈文档第 11 节的逐帧录像、减弱闪光和关闭震屏检查。
4. 成片逐帧检查 A4、A5、A6。
5. 试玩包在仓库外的新目录启动并通关。

### 5.2 真人试玩

| 项 | 做法 |
|---|---|
| 试玩者 | 需求方作风格与手感取舍；至少 3 位未读方案、未看过试片的新手用于首玩统计。内部调片人员单列 |
| 设备 | Windows PC、鼠标、普通难度、开声音；记录刷新率与使用的版本 |
| 第一遍 | 只告知"左键出剑，右键收剑"。不预告保护区、扫描、藤索或题材关键词，不演示。记录自发操作、误判位置和第一次死亡。续关单列 |
| 是否重玩 | 首轮结束先让玩家自行选"再打一局"或"结束"，记录选择及理由；主动退出或不愿再试也列入结果。再做问卷和受邀重玩。另问是否想看后续剧情 |
| 美术评审 | 先让玩家描述看见了什么、凭什么这样判断，再问喜好（1–5 分）。分别展示同机位有／无 HUD 画面，区别目标本身不清楚与反馈遮挡 |
| 视听辨认 | 用 E6 的正常、受击、误伤等分支凑齐全部 6 类，随机播放短片，分别静音看、闭屏听，记录每类被认成了什么。保留真实音量与材质声，同一人不连续看、听同一个例子 |
| 新旧反馈 | 首玩结束后再比较。固定输入、镜头、难度、音乐及音量，只换反馈版本；交换两版呈现顺序。分别以 1–5 分评价力度与结果清晰度，请玩家指出印象最深的一剑及原因 |
| 开放题 | 哪个目标最难辨认？哪一剑最想再打一次？请指出具体画面或声音 |

按原始人数报告，例如 2/3。G4、G5 和风格辨认用全体首玩新手为分母；G3 每项同时报到达人数／总人数、首次成功人数／首见人数。预先固定 G3 的成功口径：隐狐首秀必须等到现形才首次扣扳机并命中；飞针、藤索、燃料囊各看首窗第一剑，补射与续关另记。G4 接受玩家自己提前收剑，此时“剑尽→收剑”的时差记为不适用。G5 计数只认自选再开一局，续关、受邀重测和直接退出分别记录。某机制首见样本不足 3 人时记“证据不足”，补测用未看过该机制的人。6 类辨认和风格偏好分开记。小样本用于本轮制作决定，不能推算玩家总体偏好。设备与设置、输入回放、录像和问卷只在本地保存。

## 7. MVP 之后的决策

| 结果 | 下一步 |
|---|---|
| 玩法、美术均通过 | 本 MVP 覆盖的第一章美术和 Windows 鼠标玩法可用于 M1，按 P1 分片型重算剩余 49 个视频；完整 M0-B/C、M0-D/E 和 Android 仍按总案里程碑验收 |
| 接力不够快 | 用最慢的真实剪点比较原版与短击毁版，记录 T_open 和目标可读性。局部修正仍失败时，再把玩法方向交需求方决定 |
| 打击感或重玩意愿不足 | 结合 G2、G5 和玩家指出的具体片段，区分瞄准、切镜、反馈与玩法单调；仅修并复测受影响项。可保留已通过的美术，暂缓依赖失败玩法的批量镜头 |
| 看不懂某个机制 | 改提示、构图或窗口，只返工该机制的素材 |
| 风格在视频里不成立 | 停止批量，回到 A-1 调整公共风格段和视频前缀；仍不行就重新讨论美术方向 |
| 人物不一致 | 先修参考与构图；同一角色复测仍漂移，再评估 LoRA 的收益和新增成本 |
| 机关兽不可信 | 改敌人设定图，重新出动态试片 |
| 成本过高 | 用已选波次试剪两个入口，重测最早、最晚与两锚之间的命中；接力与接缝通过后才改入口数并重估，不直接删掉验收路线 |
