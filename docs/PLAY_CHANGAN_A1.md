# 长安灯妖录 · 朱雀大街巡灯

将压缩包完整解压，双击 `Changan.exe`。在标题画面按数字键 1、2、3 选择简单、普通或困难，按 Enter 开始。默认难度为普通。

移动鼠标瞄准，左键施符，右键或 R 换匣。每匣八支符箭。青火出手后仍可瞄准飞行中的火球拦截。挑担的灯贩穿过街心时收弩，让她走过。狐火少女受击后会恢复架势，等她再次现身再出手。

能量槽满时按空格或鼠标中键释放雷符。Esc 暂停，F11 切换全屏，F3 显示本帧可击区域。

F2 启用 TVGun 并显示定位白框。手机端选择 UDP 游戏模式，摄像头对准整个白框，按「开始」。扳机施符，屏外射击或「换弹」换匣，「雷符」释放满槽雷符。失锁时游戏自动暂停，重新定位后按「开始」继续。
