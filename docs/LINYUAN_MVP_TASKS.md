# 《临渊御剑》MVP 开发任务书

2026-11-26 · Windows x64 · 普通难度 · 鼠标。**Windows 可玩包已交付，素材自动选片与工程验收结果见 [MVP 验收报告](LINYUAN_MVP_QA.md)。需求方实玩、显示器两档背光和三人首玩仍待真人执行。**

交付一个能在仓库外离线试玩的版本。玩家在面摊认识陆沉和青萍，出一剑救下被毕方攫住的云姨，再进竹海打完十个节点，最后自己选择重玩或结束。参考路线约 62 秒。这个切片要回答两个问题：玩家在明亮、细节多的山水里看得清什么，以及打完后愿不愿自己再打一局。

**从 T01 开始派工。** T01 交出清单与接口样例后，美术接 T02、引擎接 T03、声音接 T05。T04 在世界入口打通后接入反馈。第一笔视频预算只覆盖 4 个 ID、12 个候选。需求方在临渊真片上出过剑并通过 T06 后，才投另外 32 个视频。工程可用占位片提前验证规则。完整切片交给新手后，再决定第一章余下 49 个视频的去留。

## QA 回放与真人验收

| 用例 | 操作 | 必须观察到的结果 |
|---|---|---|
| Q01 正常无伤 | 从标题点开始，救云姨。S5 两轮各拦针再刺芯。分别跑部分收剑和直击弱点全程免收剑路线。最后打藤索 | S3 +1000。S5 常规脚本 13/13、2 次成功拦截、主动召回两柄、余 3 剑、3 命、10 节点、11 只击毁。结果页停在竹排已落的背景。点重玩回面摊，上一局得分不带入 |
| Q02 剧情一剑 | 分别打囊、打空、等超时、打云姨右前臂。测窗前、首帧、末个有效帧、关闭帧，以及人身边缘的辅助瞄准 | 只取一个分支。囊命中走 hit，余三项走 miss，日志可区分三因。误伤后为 2 命、−100 分进 S5，仍满匣。空过窗口不得出现玩家剑痕。暂停不吃掉 2 秒窗口，持续按键不能穿过转场 |
| Q03 扫描与普通接力 | 石祠首秀扫描前抢射、扫描后命中。竹丛再次现形。五种普通波次各打早、中、晚，再抽入口分界前后及窗两端。分别打狻猊身体、肩罐，并让一只普通怪攻击抵达 | 两次隐狐扫描前均可消耗一柄空射，仅显示实际落点的材质反馈。五波共 15 条击毁片均可到达，立即按实际显示帧结算，匹配所选姿态。精准弱点返还当柄；第 8 波装甲狻猊白甲两剑、肩罐一剑。未击毁只扣 1 命再开当前节点 |
| Q04 鲮鲤 | 首轮早拦、晚拦、漏拦分别运行。飞行时打被盖住的圆芯原位置，取避开针簇的落点。首击后等下一轮发射，再次成功拦截后终击 | 每簇仅一个判定，飞行时打屋顶不能扣精英耐久。漏拦一次扣 1 命并重射，成功拦截才开芯。首剑后耐久 1，受击片接第二轮发射。超时发针不扣命，下一轮沿用耐久，第二击才完成精英。重复拦截计入实际命中，固定 150 分与连击奖励每个耐久阶段最多发一次 |
| Q05 藤索 | 分别打两个有效入口。另跑打空后补射、打下方两只兽、等待超时后重试 | 只有藤结有效。打兽按打空。到期两兽合计扣 1 命，存活留本节点。打结只消耗一剑、加 400 分、加两只击毁、推进一次。砸落尾帧保持到结果页 |
| Q06 剑匣、死亡与退出 | 测提前收剑、空扣、收剑中连点、顿帧重复扣扳机。S3 误伤后故意在 S5 连续失手至阵亡，分别选择续关或结束 | 空扣显示按键，收两柄用 0.27 秒、八柄用 0.60 秒。收剑和顿帧期间无额外消耗。两只隐狐现形前抢射按普通落空结算。续关回 S5 节点 1，3 命 8 剑，保留 S3 −100 和误伤记录，只清失败段成绩。退出、死亡、续关、自主再开新局各有独立事件 |
| Q07 手感与剪点 | 用同一源码修订分别构建长安 A1 和临渊，各录一组旧／新对照。按同一节点、显示帧、落点重放有效输入。固定设置、音量与音效随机种子。另在固定刷新率、关闭录屏及同步截图时采集输入延迟 | 普通接力逐条列 T_open−T_hit，中位目标 1.2–1.5 秒，单条 ≤1.8 秒。能看清的更快接力无需补等待。慢放、扫描首秀、精英转段、借势、受伤重试单列，战斗内各连续不可操作段 ≤2 秒。测命中输入→首次反馈提交的 P50、P95、样本数与 Hz，P50 目标 ≤一个刷新周期。分支首帧延迟另列。关震屏、减弱闪光、静音时仍能读出可射状态 |
| Q08 素材与部署 | 扫描所有引用、校验哈希和帧数。在测试副本中分别移走一片、换错掩码、破坏一个后继，跑资源检查器。用正确的临渊包执行冷启动，西部和长安回归分别在各自的新包执行 | 三个坏样本均明确报错，正确包无占位和仓库外路径依赖。亮度两档在同屏上以 960×540 无 HUD 正速比较，记录识别出错的具体帧和位置。这轮由内部评审记录所见，新手对人物、机关、武器和动作的独立辨认留给 T12 |

**记录协议。** 用同一单调时钟关联输入、首次可打帧、实际显示帧、命中、分支、首次反馈提交和收剑开始／完成。每行至少含局与尝试编号、阶段／节点、媒体 ID、显示的源帧、事件与结果。射击行保存落点和引发的状态变化。接力等待含顿帧和解码。玩家反应、收剑及暂停单列。真人首玩用可见窗口和真实鼠标，单开日志。旧版 `--smoke` 会注入自动输入。对照回放按记录的源帧与事件执行，允许两版顿帧使墙钟不同，同时检查命中和分支相同。

**真人门槛。** 首玩只讲左键出剑、右键收剑。G3 四种首见机制各至少半数在第一窗成功。各报首次到达／总人数和成功／到达人数。单项首见不足 3 人时补未见过该机制的人。G4 超过半数首轮无续关通关且自行收剑。G5 至少三分之二主动再开一局。六类结果的静音和盲听辨认分别逐类至少三分之二正确。风格识别和 960×540 的可读性按 MVP §1.2–1.3 验。首轮退出者保留在全体分母中。需求方亲自判断风格与反馈，报告用 2/3 这样的原始人数，并附玩家指认的具体画面或声音。
