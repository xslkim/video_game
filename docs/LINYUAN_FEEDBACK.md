# 《临渊御剑》反馈与打击感设计 v1.5

修订于 2026-11-26。画面是明亮的山水场景，准星和标记一律带深色描边，闪白按目标剪影提亮。本文展开[策划案第 8 节](LINYUAN_PLAN.md#8-打击感规格)的反馈规格。战斗段、剧情一剑和 Boss 分阵共用同一套事件，Windows 和 Android 按设备刷新率与画质档呈现。

文中 F0 是引擎结算事件后首次提交反馈的画面。F1、F2 等按 60 Hz 参考时间轴计，每格约 16.7 毫秒；30 Hz 设备在实际刷新时采样同一条曲线，F0 的关键标记至少显示一次。视频帧号另按素材帧率记录。坐标以 1280 × 720 视频为准，其他分辨率等比缩放。

---

## 1. 长安的问题出在哪里

对照长安 1.0 的代码，问题不在参数，而在于整套反馈只用了 SDL 的线和矩形：

| 项 | 长安的实现 | 玩家看到的 |
|---|---|---|
| 准星 | 半径 8 像素、1 像素粗的圆加 4 条短线，米白色，没有描边（`changan.cpp` 的 `drawHud`） | 亮背景上看不见，暗背景上太细；准星没有任何状态变化 |
| 威胁预警 | 1 像素圆环，透明度 148，半径随攻击帧收缩 | 很难注意到，看不出"它要打我了" |
| 命中 | 一个从 12 像素扩到约 50 像素的 1 像素圆环，加 16 个 3 × 3 的方块，固定角度、匀速外扩，0.45 秒线性淡出（`drawEffect`） | 像 UI 动画，不像击中东西。命中、净化、拦截、打空几乎是同一个效果 |
| 顿帧 | 小妖 50 毫秒，精英 120 毫秒（`changan_game.cpp`） | 有顿帧，但画面上没有配合的闪白和冲击，顿帧反而像卡顿 |
| 目标闪白 | 方案写了"按掩码白闪 2 帧"，代码里没有实现 | — |
| 震屏 | 没有 | 命中和受击都没有重量 |
| 得分 | 只在 HUD 角落更新数字 | 命中点没有得分飘字，没有命中标记 |
| 玩家受击 | 屏幕上下各一条 13 像素红条，中间写"受击"两个字，0.45 秒淡出 | 不疼，也看不出是谁、从哪个方向打的 |
| 弹药 | 屏幕左上角 8 个小方块 | 射击时视线要离开目标去看角落 |
| Android | `game.js` 同样是 0.45 秒的圆环 | 同上 |

结论：

1. **缺素材。** 没有发光贴图、粒子贴图、裂纹贴图，所有效果都是 1 像素的几何线。
2. **缺分层。** 一次命中应该有"确认—冲击—碎裂—余韵"几层，长安只有一层。
3. **缺区分。** 命中、击毁、格挡、打空、拦截、受击，强度和样子应该完全不同。
4. **缺时间曲线。** 全部是线性淡出。冲击感来自第一帧最强、随后快速衰减（ease-out），再加一段长尾。
5. **缺身体反应。** 没有震屏，没有画面冲击，没有声音闷压。

## 2. 设计原则

1. **F0 必须有反馈。** 以扳机对应的已显示帧判定，在下一次画面提交时绘制剑痕及该结果的标记，同轮向混音器投递声音。打空只画剑痕与落点效果，空匣只提示收剑。
2. **分层叠加。** 每次命中由视觉、声音、时间（顿帧）、镜头（震屏）、HUD 五个通道同时表达，强度按事件等级统一分配（第 3 节）。
3. **一眼能分清。** 命中、击毁、格挡、打空、拦截、受击、误伤各有独有的颜色、形状和声音。玩家关掉声音能分清，闭上眼也能听出来。
4. **色彩语义固定。**

| 颜色 | 色值 | 只用于 |
|---|---|---|
| 青 | `#4DFFD2` | 玩家：飞剑、准星、命中、收剑 |
| 金 | `#FFC94A` | 奖励：弱点、击毁精英、拦截、得分、剧情一剑目标 |
| 红橙 | `#FF4A2E` | 威胁：敌人蓄力、投射物、玩家受击 |
| 冰白 | `#CFE3FF` | 保护：被劫持的人、不能打的东西 |
| 灰 | `#8C939B` | 无效：护盾、格挡、剑尽 |

   天机的蓝色只在视频里出现，引擎不使用蓝色，避免和青色混淆。

5. **保留下一个目标的视野。** 常规命中闪光半径最多 160 像素，250 毫秒内淡到 30% 以下。全屏闪仅用于玩家受击和 L4 事件，范围限游戏画面，受第 10.5 节的统一上限约束。
6. **反馈跟着判定走。** 先用扳机所对应的显示记录逆算视频坐标，计入视口、出血裁切、缩放与震屏。落点和局部特效锚定在视频坐标，HUD、准星、字幕和 TVGun 定位边框保持固定。边框、暗带、留黑区均在场内效果范围之外。

每次受理的普通出剑消耗一柄飞剑，命中或打空只结算一种结果。选定命中分支后即锁定，顿帧冻结视频、片内音轨、攻击时钟与判定窗口。其间的额外扳机输入丢弃，恢复后接受新输入。反馈音和粒子按实际时间继续。接力等待从上一次决定击毁的命中计到下一目标首次可射，包含顿帧与切片耗时。

## 3. 强度等级

| 等级 | 事件 | 顿帧 | 震屏 | 闪光 | 粒子 | 声音层数 |
|---|---|---|---|---|---|---|
| L0 | 打空、格挡 | 无 | 无 | 小 | 6–10 | 1–2 |
| L1 | 命中未击毁（精英、Boss 扣血） | 60 毫秒 | 3 像素，100 毫秒 | 中 | 16–24 | 2 |
| L2 | 击毁小怪、拦截、解救 | 70 毫秒 | 4 像素，120 毫秒 | 中加二段闪 | 24–36 | 3 |
| L3 | 击毁精英、Boss 换阶段 | 140 毫秒 | 8 像素，250 毫秒 | 大，色差脉冲 | 40–60 | 4 |
| L4 | Boss 终结、心剑；万剑归宗的时序另见第 9 节 | 终结与心剑顿帧 250 毫秒，随后 0.5 倍慢放 400 毫秒 | 12 像素，450 毫秒 | 全屏 | 80–120 | 4 加音乐闷压 |
| 受击 | 玩家受到攻击 | 90 毫秒 | 14 像素，300 毫秒 | 全屏 | 按攻击类型 | 3 加全局闷压 |

本表给出默认强度。解救使用断链光点，万剑归宗使用专用时间线。M0-A 实玩后若调整数值，同步下文的事件时间线。

## 4. 准星

### 4.1 形状

- 中心一个 3 像素的点，外圈 4 段弧，半径 16 像素，每段 50°，弧之间留缺口。整体像剑诀环。
- 线宽 2.5 像素，外加 1.5 像素的深色描边（黑色，透明度 55%）。任何背景下都看得清，这是对长安最直接的修正。
- 准星下方是一圈 8 个短刻度，排在半径 24 像素、从 200° 到 340° 的弧上，每个刻度代表一柄飞剑。弹药就在视线中心，不用再看角落。HUD 角落的剑匣图标保留。

### 4.2 状态

| 状态 | 表现 |
|---|---|
| 常态 | 白色（`#F2F5F7`） |
| 指向可命中目标 | 变青，4 段弧在 80 毫秒内收到半径 12 像素，像吸附上去 |
| 指向弱点 | 青色，中心点换成金色小菱形 |
| 指向保护对象 | 冰白，弧张开到 20 像素，中间加一条斜杠 |
| 指向护盾 | 灰色，弧改为虚线 |
| 出剑 | 弧向外弹 5 像素，再用阻尼弹簧在 90 毫秒内回位；4 段弧顺时针转 15°；一个刻度化成一小道青光飞向右下方 |
| 剑尽 | 刻度熄灭，准星变灰，每秒闪 3 次。Windows 鼠标首次空匣时，在准星下方显示带描边的“右键或 R 收剑”，直至开始收剑 |
| 收剑中 | 刻度按顺时针依次点亮，满了以后整圈亮一下，伴随"咔"的一声 |
| 万剑归宗可用 | 外圈多出一圈缓慢旋转的细剑阵纹样 |
| 受击后 | 红色闪两次，共 300 毫秒 |

指向状态按当前显示帧复用射击判定，简单和普通难度默认开启，困难默认关闭。TVGun 默认隐藏随枪移动的准星、刻度和指向提示，弹药与收剑进度常驻角落 HUD，开火后仍在实际落点展示结果标记。触屏使用相同的落点标记和角落弹药显示。

### 4.3 命中标记

画在命中点上，与准星是否显示无关。

| 结果 | 标记 |
|---|---|
| 命中未击毁 | 4 道白色短斜线组成的 ×，从 10 像素扩到 14 像素，100 毫秒；重甲敌人白甲受击额外弹出“破甲”飘字并触发 60 毫秒原地受击定格 |
| 击毁 | 加粗的 ×，线宽 3.5 像素，从 14 像素扩到 20 像素，F0 中心有 1 帧白色亮点，180 毫秒 |
| 弱点 | 沿用当次“命中未击毁”或“击毁”的线宽、大小和时长，标记改为金色，中心另加菱形闪光，弹出金色“弱点回剑 +得分”飘字，100 毫秒顿帧后飞剑沿弧线飞回剑匣。鲮鲤的圆芯连续受两剑，两次的轮廓和声音须能分辨 |
| 格挡 | 灰色的 ⊘，120 毫秒 |
| 拦截 | 青色圆环迸开加金色 × |
| 误伤 | 冰白的大 ⊘，400 毫秒 |

## 5. 目标与威胁指示

### 5.1 现身提示

新目标进入首个可命中帧时，在它的掩码中心出现青萍的扫描：一道 1.5 像素的青色细环从 0 扩到 40 像素，同时目标包围框的四个角从 1.3 倍大小收到 1 倍，用时 120 毫秒，350 毫秒内淡出。同时播一声短促的"滴"，按目标的横向位置做立体声声像，左边的目标从左声道响。

| 难度 | 规则 |
|---|---|
| 简单 | 每个目标都提示 |
| 普通 | 目标出现在画面中央 40% 以外，或这种敌人第一次出现时提示 |
| 困难 | 只有声音，没有画面提示 |

提示服从关卡的可见信息。隐狐在现形前只留视频里的落叶和光斑轮廓。雨中辨真时，各候选共用相同的指向样式、现身提示与瞄准辅助条件，玩家靠雨花辨别；金色弱点环在谜题解开、核心正式暴露后才出现。

### 5.2 蓄力预警与临近红芒

替换长安的细圆环，采用“外围蓄力信号 + 攻击源红芒点”双层预警：

- 从预警帧开始，红橙色的四角括号框住目标包围框，外侧一条倒计时弧随剩余时间缩短，屏幕四周同步泛起脉冲红晕。
- **最后 0.5 秒危急红芒（`threat_glows.json`）**：在 `impact_frame` 前最后 0.5 秒（`12 × speed` 帧），引擎按逐帧绑定的攻击源坐标（如狻猊与隐狐的双瞳／兽口、毕方赤瞳、鲮鲤针巢，支持单帧 1–2 个发光锚点）叠加高频脉动的赤橙红芒（`threatGlow`），配合三声逐级升高的“嘀”，把玩家视线直接拉向即将出招的部位。静音或开启减弱闪光时仍能看见倒计时弧与红芒中心核。
- 攻击帧（抵达帧）括号整体亮成实心红，随即进入玩家受击（第 7 节）。
- 包围框由当帧掩码的行段计算，跟着目标移动。

### 5.3 投射物

每簇针使用同一个拦截区和倒计时弧。飞针在空中锁圆芯，成功拦截后露芯。首剑刺芯后鳞扇闭合，进入 `elite_launch`（1.2 倍速）再发第二簇；漏拦一次对应一次扣命。攻击最后半秒叠加针巢红芒与三声升调警示。

### 5.4 弱点、护盾和保护对象

| 对象 | 指示 |
|---|---|
| 弱点暴露 | 暴露窗口期间，引擎对 `.weak.mask` 行段按连通域聚类（`findWeakSpots`，间隔阈值 `maxGap = 4`），在每个独立弱点部件中心（如隐狐的额心与尾枢双弱点、狻猊的双肩罐）分别绘制每秒 2 次脉动的金色圆环与金色闪光。**弱点与瞄准辅助分离**：机身命中享受 12 像素辅助半径（`aimCovers`），而弱点判定要求无辅助直接命中（`weakAt`），防止擦边辅助误触发弱点回剑；重甲敌人（`hp > 1, weak_damage == hp`）在 HUD 提示“白甲 N 剑 · 肩罐 1 剑” |
| 护盾 | 视频保留举盾动作。开启指向提示时，准星移上盾面变为灰色虚线；击中盾面时闪一层灰色六边形纹，150 毫秒 |
| 被控制的人 | 第一次出现时，人物轮廓描一圈冰白细线，500 毫秒淡出。可打的天机接口或天机链上加青色小括号 |
| 剧情一剑目标 | 保持人体与器件处的中间调，只在外围加轻微暗角；燃料囊处用金色环与深色细描边随窗口收缩。`c1_10_talon` 慢放前 0.5 秒（72–77 帧）由翼羽半遮燃料囊，后 1.5 秒（78–95 帧）完全敞开 |

### 5.5 HUD 文字

操作说明仅用于前两次教学和剑尽提示。战斗喊话照常配中文字幕，把字幕置于行动区之外。所有引擎绘制的文字带 2 像素深色描边。

## 6. 敌人受击

### 6.1 一次击毁的时间线（L2，小怪）

| 帧 | 内容 |
|---|---|
| F0–F9 | **立体飞剑与归匣闭环（`linyuan_sword.hpp`）**。底部剑匣口设 8 个獨立槽位（`caseMouth(slot)`，横跨 `x = 598..682, y = 706`）。出剑后飞剑在 160 毫秒内沿二次贝塞尔弧线（`SwordArc`）掠向落点：底层绘制加法混合的青金渐变剑气飘带（`swordRibbon`），剑体绘制五段式立体构件（剑首圆镡、深色剑柄、青铜护手横格、双刃剑脊与血槽、亮白剑锋），145 毫秒抵达落点时迸开十字斜劈斩痕（`impactSlash`）。未回剑的飞剑记录落点槽位（`spentSwords[8]`）；直击琥珀弱点时在 100 毫秒顿帧后自行沿弧线飞回对应匣槽（`returnSword`），主动收剑时所有留场飞剑按动态耗时（`0.16 + 0.055 × 已出剑数` 秒）同步掠回匣口并亮起归匣剑光（`caseGlint`） |
| F0 | **命中闪光**：白色核心 90 像素，F0–F1 满亮度；青色光晕 160 像素，到 F6 衰减完 |
| F0 | **剪影闪白**：用当帧掩码把目标整个填成白色（加法混合，透明度 85%），F0–F2；F3–F4 降到 40%，同时剪影向外扩 3 像素、模糊，形成一圈光边 |
| F0 | 命中标记，第一层声音（瞬态） |
| F0–F4 | 顿帧 70 毫秒：视频停在命中那一帧，效果和粒子继续运动 |
| F0 | 震屏 4 像素、120 毫秒，外加沿飞剑方向的一次 3 像素推力 |
| F1–F27 | **火花**：24–36 道。初速每秒 300–900 像素，喷向飞剑来向的反射方向，扩散 120°，有阻力和重力。每道画成沿速度方向拉长的光条，颜色从白到橙到红，寿命 0.2–0.45 秒 |
| F1–F50 | **材质碎片**，按敌人材质（第 6.3 节） |

| F3 | **二段闪**：命中点再亮一下，比 F0 小一半，配合第二层声音（碎裂），形成"打中—炸开"的两拍 |
| F5 起 | 视频恢复播放，进入击毁片段。引擎的粒子和烟延续到击毁片段的前 0.5 秒 |
| F5–F48 | 机械类敌人加 2–3 团深灰色烟，缓慢上升，0.8 秒 |

### 6.2 各等级的差别

| 事件 | 与 L2 的差别 |
|---|---|
| 命中未击毁（L1） | 没有二段闪和冲击环；顿帧 60 毫秒；粒子减为 16–24。精英头顶出现血量格，每打一次碎掉一格，碎格迸成 4 片，1.2 秒后血量格淡出 |
| 击毁精英（L3） | 顿帧 140 毫秒；色差脉冲 2 像素、100 毫秒；画面放大 1.5%（120 毫秒，回弹）；粒子 40–60；冲击环加大到 120 像素；第四层声音是低频轰鸣 |
| Boss 换阶段（L3） | 同上，另加 0.3 秒画面四周压暗 |
| Boss 终结（L4） | 顿帧 250 毫秒，随后 0.5 倍慢放 400 毫秒；全屏白闪 2 帧（透明度 50%）；震屏 12 像素；粒子 80–120；音乐在 600 毫秒内压低 8 分贝再回升 |
| 弱点 | 闪光、标记和飘字改成金色；多一圈金色火花 |
| 拦截（L2） | 投射物处炸开一个青色大环，加 30 道火花；按 L2 顿帧 70 毫秒，场内其他投射物的抵达计时同步冻结；金色飘字“拦截 +150” |
| 解救（L2） | 接口处的电弧加冰白的断链光点。不做剪影闪白，不放火花雨，避免像在打人；"解救 +300"用冰白色 |
| 格挡（L0） | 没有顿帧、没有闪白、没有震屏。10 道橙色火花按镜面方向弹开；剑痕弹道到达命中点后折出一小段，飞剑打着转飞走，150 毫秒；灰色 ⊘ 标记；清脆的"叮" |
| 打空（L0） | 没有顿帧、没有震屏。按落点材质：水面溅起 6 滴水和一圈压扁的涟漪；石面和金属处 6 道火星加 1 秒的焦痕；土地和草地扬起一小团尘土；竹木上崩出几片竹屑。声音按材质 |

### 6.3 材质

每种敌人在数据里登记一个材质，决定碎片和声音。

| 材质 | 敌人 | 碎片 | 声音 |
|---|---|---|---|
| 陶瓷甲 | 狻猊、隐狐、剑螳、旋龟、鲮鲤、饕餮的机身 | 8–12 片米白色三角甲片，6–14 像素，旋转下落，带一点明暗，0.6–0.9 秒；另加几缕黑色纤维 | 陶瓷甲碎裂加液压的断裂声 |
| 翼片 | 毕方 | 6–8 片细长的白色翼片，打着旋飘落，1 团短烟 | 翼片撕裂声加坠落的风声 |
| 琥珀部件 | 狻猊肩罐、毕方燃料囊、鲮鲤圆芯等 | 命中点迸出琥珀色火星。狻猊肩罐由成片拍出飞离机身的动作，引擎剪影只叠在该罐体上。鲮鲤圆芯首击留在鳞扇上，终击随片爆裂 | 首击播放金属命中声，部件炸开时加爆裂闷响。液体喷溅声用于燃料囊和罐体 |
| 天机接口 | 被控制者的后颈接口、天机链 | 3 道每 2 帧重画一次的折线电弧（冰白），4 点小火花 | 短路的噼啪声 |
| 幻影 | 谢无咎的雨中幻影 | 青色像素方块碎散，画面横向错位 2 帧 | 数字信号撕裂声 |
| 铜身 | 了尘的控制节点 | 节点处冰白断链电弧加少量铜色火花 | 铜钟般的回响 |

每个固定机位的场面在母版定稿后涂一张 64 × 36 材质格（水面、石面、金属、土地、竹木、空中），按反算的画面落点选择打空效果。玄武背上的移动镜头、未标注位置和空中落点只播短破空声与剑痕。切换镜头时清除上一机位的贴花。

## 7. 玩家受击

### 7.1 时间线

Windows MVP 实装采用红色渐变暗角。爪击、冲撞和飞针分别绘制斜向爪痕、分叉裂纹和由屏边向内的冲击线，约 340 毫秒后退去。上方的扣命与余命提示保留到 780 毫秒；减弱闪光和关闭震屏时同样可读。表内的色差、振动等属于完整版演出目标。

| 帧 | 内容 |
|---|---|
| 预警 | 第 5.2 节的红色括号和倒计时 |
| F0 | 视频到达攻击帧。顿帧 90 毫秒，让玩家看清"被打中"的那一下 |
| F0 | **全屏闪**：1 帧，透明度 35%。物理攻击和爆炸用红橙色，电击用冰白色 |
| F0–F48 | **方向光**：朝攻击者的那一侧屏幕边缘亮起一道红色月牙形辉光，0.8 秒淡出。方向由攻击者中心相对屏幕中心的位置决定；正面中央的攻击改为整圈暗角 |
| F0–F18 | **震屏** 14 像素、300 毫秒，外加一次背离攻击者方向的 10 像素推力 |
| F0–F18 | **色差**：红色通道错开 6 像素，300 毫秒内收回 |
| F0–F30 | **染红**：全画面乘一层偏红的颜色，500 毫秒内退去 |
| F0–F60 | **攻击类型叠层**，见第 7.2 节 |
| F0 | **HUD**：一个生命图标（青色剑穗）先抖 100 毫秒，再碎成 6 片落下；剩下的生命图标闪红 |
| F0 | **声音**：沉重撞击、攻击类型层、全局低通闷压（其他声音的高频在 500 毫秒内衰减到 800Hz 再恢复）、轻微耳鸣 |
| F0 | **振动**：手柄强振 250 毫秒；Android 触屏模式振动 120 毫秒。TVGun 手机振动需要扩展协议，放到 M4 |
| 之后 | 准星红闪两次。本轮伤害只结算一次（沿用长安规则），叠层继续淡出，不锁输入 |

### 7.2 攻击类型叠层

| 攻击 | 叠层 |
|---|---|
| 扑咬（狻猊、隐狐、饕餮） | 三道斜向的爪痕横过屏幕，加一圈碎屑，1 秒淡出 |
| 撞击（毕方俯冲、饕餮冲撞） | 以撞击点为中心的放射状裂纹，加一圈碎屑和火花 |
| 爆炸（暴雨梨花、火珠、火镖） | 橙色闪光，屏幕四边涌入 6 团烟，火星在 1 秒内往下落 |
| 罡气（了尘） | 一圈向外推开的气浪，画面短暂扭曲成向外的放射模糊（低端机用暗角替代） |
| 飞剑（谢无咎） | 一道白色斜向的划痕横过屏幕，0.6 秒 |

裂纹、划痕、烟和气浪的贴图作为引擎素材制作（第 10 节），每种 2–3 个变体随机选用。

### 7.3 残血与阵亡

- **剩 1 条命**：屏幕四周保持一圈缓慢脉动的红色暗角，配每分钟 70 次的心跳声，HUD 生命图标持续闪烁。
- **阵亡**：0.5 倍慢放 600 毫秒，画面定格，裂纹布满全屏后碎成块向下掉落，露出黑底，进入续关画面。

### 7.4 误伤

误伤被劫持的人，和被敌人打中必须完全不同：

- 顿帧 120 毫秒，命中点出现冰白的大 ⊘ 和局部冷白光。
- 误伤立即播放独立的低沉错误音。MVP 的救云姨一剑用此音配合冰白禁射标记；完整第一章再接青萍的 `qingping/protect`（“别打人！”）。
- 按难度扣命（简单只扣分）。扣命时生命图标同样碎裂。

## 8. 声音

| 事件 | 层次 |
|---|---|
| 出剑 | 破空声加金属清鸣，按准星横向位置做声像 |
| 命中 | 瞬态击打声，加材质层（第 6.3 节）；连击每升 5 次音调升一个半音，上限 12 个半音 |
| 击毁 | 命中层，加 F3 的碎裂层，加低频重击 |
| 击毁精英 | 再加一层次低频轰鸣；音乐闪避 3 分贝，300 毫秒 |
| 格挡 | 高频的"叮"，没有低频 |
| 打空 | 按材质：落水、石面跳弹、土地闷响、竹木的脆响 |
| 拦截 | 玻璃爆裂加一声清亮的钟 |
| 现身提示 | 短促的"滴"，带声像 |
| 蓄力预警 | 逐级升高的三声"嘀"，最后一声与攻击帧对齐 |
| 受击 | 第 7.1 节 |
| 收剑 | 按实际召回剑数（1–8 柄）连续触发对应次数的"咔哒"归鞘声（耗时 `0.16 + 0.055 × 召回剑数` 秒），最后一声最重 |
| 剑尽扣扳机 | 剑匣空响 |
| 万剑归宗 | 8 声剑鸣依次叠起，最后是一记重低频冲击 |

- 每个事件 3–5 个变体，随机挑选，音高随机浮动 ±4%。
- 开火、打空、收剑等共用短音效常驻，场景专属材质和攻击音在进场前预载，离场后释放。首次扣扳机时即可向混音器投递反馈音。
- 每次命中时音乐闪避 2 分贝、150 毫秒。命中声比音乐响约 6 分贝。混音电平以 M0-A 实录为准，长安的音效与配乐的相对响度需要一起复查。
- 战斗中所有音效都按画面横向位置做声像，范围 −0.6 到 0.6。

Windows MVP 的竹海保留一首循环战斗曲。普通命中、精英击破和玩家受击分别让配乐短暂下降约 2、3、5 分贝，对应回升时间为 150、300、420 毫秒。出剑的三个变体共享短促的金属起音，三类受击保留各自的材质声，并共享两段下沉重音。对白单独混音。

## 9. 万剑归宗

受理 SPECIAL 时按当前显示帧检查充能、目标和暴露窗口。有效释放只消耗一次充能、结算一次伤害，八道剑痕均为表现。锁定阶段或没有合法目标时保留充能。第三章心剑由普通扳机触发，走独立剧情窗口。

| 帧 | 内容 |
|---|---|
| F0 | 分支已锁定，视频慢放到 0.3 倍，持续 250 毫秒；画面四周压暗；剑意槽的光沿 HUD 飞向落点 |
| F0–F15 | 8 道剑痕从屏幕四周依次射向目标，每道间隔 30 毫秒，每道到达时有一次小闪光和"铮"的一声 |
| F15 | 恢复正常速度。目标处爆开全屏白闪 2 帧，冲击环 200 像素，粒子 100，震屏 12 像素、450 毫秒，重低频 |
| 之后 | 直接进入已选的击毁、精英受击或 Boss 暴露分支。此次释放只播放这一组闪光和慢放，包括它触发阶段切换或终结时 |

## 10. 实现

### 10.1 渲染

不必先换 GL。SDL3 的 `SDL_Renderer` 支持贴图、颜色调制、加法混合（`SDL_BLENDMODE_ADD`）、乘法混合（`SDL_BLENDMODE_MUL`）和 `SDL_RenderGeometry`，足够实现本文的全部效果：

| 效果 | 做法 |
|---|---|
| 粗线、弧、环 | `SDL_RenderGeometry` 画三角形条带，贴一张横向柔边的渐变贴图，边缘自然抗锯齿 |
| 闪光、光晕、烟 | 启动时程序生成径向渐变贴图，加法混合 |
| 火花 | 沿速度方向拉长的四边形，贴光条贴图 |
| 碎片 | 带旋转的三角形，普通混合 |
| 剪影闪白 | 结算命中时，用该显示帧的可见掩码或 Boss 区域多边形生成带透明通道的剪影并缓存到效果结束。按档位画一遍本体、可选一遍柔边。解救与误伤只标出落点 |
| 包围框 | 按当帧掩码行段或可见区域多边形求边界 |
| 色差 | 受击、击毁精英或 Boss 换阶段时，在对应效果时段将视频的红通道偏移，与青通道加法合成。预算不足时改用暗角 |
| 染红 | 全屏方块，颜色 (255, 150, 150)，乘法混合 |
| 震屏 | 视频层和场内特效层整体偏移。平滑噪声与推力合成后按每轴实际出血量限幅，使用限幅后的变换回查命中。优先保住可射区域和定位框，最大 4% 出血在 M0 试调 |
| 慢放 | 视频和片内音轨降速，特效用实际时间 |

### 10.2 引擎素材

| 素材 | 数量 | 来源 |
|---|---|---|
| 径向光晕、光条、柔边渐变、烟团 | 各 1 | 启动时程序生成 |
| 屏幕裂纹（电击、撞击） | 各 3 | 出黑底白线的图，由工具转换成带透明度的 32 位 BMP |
| 划痕、气浪 | 各 2 | 同上 |
| 生命图标（剑穗）及碎片 | 1 套 | 同上 |
| 飞剑刻度、剑匣图标 | 1 套 | 同上 |
| 字体 | — | 沿用系统中文字体，文字加描边 |

BMP 与长安的标题图一致，SDL 自带读取，不增加依赖。

### 10.3 数据规范

引擎在加载 `level.json`、`threat_glows.json` 与战役清单时对以下数据驱动字段做强校验（未显式声明时回退至旧版媒体名启发式，保证旧关卡兼容）：

| 字段 | 位置 | 取值与校验规范 | 用途 |
|---|---|---|---|
| `material` | 敌人节点（`nodes[]`） | `"ceramic" \| "feather" \| "vine" \| "crystal" \| "metal" \| "phantom"` | 驱动 `scatterArmor` 旋转三角甲片／羽片／藤屑及对应材质受击音（`hit_ceramic`、`hit_wing` 等） |
| `tier` | 敌人节点（`nodes[]`） | `1 \| 2 \| 3`（可选，默认按血量与精英推断） | 驱动击破闪光层级、震屏幅度与配乐闪避深度（如鲮鲤 `tier: 3`、重甲狻猊与藤索 `tier: 2`） |
| `weak_damage` | 敌人节点（`nodes[]`） | `1 <= weak_damage <= hp`（默认 `1`） | 重甲差异伤害：当 `hp > 1` 且 `weak_damage == hp`（如第 8 波重甲狻猊 `hp: 2, weak_damage: 2`），打白甲扣 1 血并原地定格 60ms（“破甲”），无辅助直击琥珀弱点直接扣满 `weak_damage` 一剑秒杀并回剑 |
| `attack` | 片段（`clips{}`） | `"claw" \| "collision" \| "blast"` | 按 §7.2 选择玩家受击屏幕叠层（爪痕／撞击裂纹／飞针冲击）与受击音效（`hurt_claw / hurt_impact / hurt_blast`） |
| `allow_early_miss` | 片段（`clips{}`） | `bool`（默认 `false`，隐狐波次设为 `true`） | 开启后，在 `start <= frame < windows[0].begin`（扫描现形前）抢射会消耗 1 柄飞剑、清空连击并在落点绘制场景材质打空反馈 |
| `speed` | 片段（`clips{}`） | `0 < speed <= 2.0`（默认 `1.0`） | 片段播放倍速（如鲮鲤二轮发针 `elite_launch` 设为 `1.2` 倍速压迫窗口） |
| `weak_mask` | 片段（`clips{}`） | `bool`（绑定 `<clip>.weak.mask`） | 琥珀弱点掩码，与全身掩码独立；由 `findWeakSpots` 自动聚类多连通域弱点环，仅无辅助直击时触发回剑与 `+weak_bonus` |
| `threat_glows.json` | 关卡目录 | `{ "<media>": { "sha256": "...", "points": [[frame, x0, y0, ...]] } }` | 绑定每条带 `impact_frame` 攻击片最后 0.5 秒（`12 × speed` 帧）的兽瞳／口器／针巢红芒坐标，哈希不一致或缺帧时拒绝加载 |
| `after_civilian` | 剧情镜头（`takes[]`） | `bool`（可选，`false` 为常规，`true` 为误伤后） | 驱动 `story_shot` 之后的剧情分流（如 `c1_12_thanks` 与 `c1_12_rebuke`） |
| `materials` | 关卡根对象 | `36 × 64` 网格（`air / water / stone / earth / bamboo / metal`） | 绑定母版哈希 `materials_sha256`，驱动打空落点的水花、火星、尘土与竹叶反馈 |

### 10.4 Android

网页客户端用 Canvas 2D 实现同一份规格：加法混合用 `globalCompositeOperation = "lighter"`，乘法用 `"multiply"`。按画质档位缩减：

| 档位 | 粒子上限 | 色差 | 剪影闪白 | 屏幕叠层 |
|---|---|---|---|---|
| PC | 3000 | 开 | 两遍 | 全部 |
| 标准 | 600 | 开 | 一遍 | 全部 |
| 省电 | 200 | 关，改为暗角 | 只画命中标记 | 只保留裂纹 |

命中标记、弹药、方向光、保护斜杠、可射窗口与投射物倒计时在各档保留。每张离线帧页按所展示画面映射回源视频局部帧号及可见区域。粒子按毫秒计算，30 Hz 时只减少采样。视频和帧页两条播放路径都要验证边缘目标及震屏中的落点。

### 10.5 设置

| 项 | 选项 |
|---|---|
| 闪光 | 标准 / 减弱。减弱时关闭全屏闪、剪影闪白与二段闪，局部辉光透明度乘 0.4，预警保留轮廓与倒计时 |
| 震屏 | 标准 / 减弱 / 关。关闭时取消画面位移、推力与冲击缩放，保留方向光和命中标记 |
| 准星 | 显示 / 隐藏（TVGun 默认隐藏） |
| 指向提示 | 开 / 关（按难度给默认值） |

各事件共享全屏闪上限，任意连续 1 秒内最多 3 次；超额只显示局部标记、方向光和声音。限幅、减弱闪光与震屏设置均作用于战斗、分阵、剧情一剑的引擎效果。

## 11. 验收

1. **逐帧录像**：PC 用 60 fps 录制。成功命中需在 F0 可见弹道和结果标记，打空需有剑痕，逐帧核对顿帧期间特效仍动、额外扳机不重复结算、下一目标不被遮挡。另用减弱闪光与关闭震屏各复查一次预警和判定。
2. **静音测试**：MVP 用真实分支覆盖命中未击毁、击毁、打空、拦截、受击、误伤六类，逐类记辨认人数。格挡在 M2 有护盾的镜头加入。
3. **盲听测试**：只听声音，单独统计同阶段各类事件的辨认人数。MVP 两种测试均依 [MVP 的 G2](LINYUAN_MVP.md#11-玩法) 验收。
4. **延迟**：记本机有效输入进入引擎至首次反馈画面提交的单调时差，按设备、刷新率和输入方式列样本数、P50、P95。设计目标为 P50 不超过一个刷新周期（60 Hz 约 16.7 毫秒，30 Hz 约 33.3 毫秒）。旧版街战 14 次的 P50 为 33.4 毫秒、P95 为 43.5 毫秒。分支首帧提交另记，电视上扳机到可见反馈另在 M4 实拍。[长安交付记录](CHANGAN_RELEASE_QA.md)
5. **对照**：同一段 M0-A 素材，分别用长安旧反馈和新反馈录两条，交需求方并排比较。
6. **分阶段验收**：M0-A 并入 Windows MVP。首批四个视频实测一次出剑、扫描与接力；完整切片在救云姨的一剑和竹海十节点验 L0–L3、玩家受击及误伤，保留新旧两版对照。M1 用第一章饕餮终结和万剑归宗补验 L4。M2 在第二章验格挡、香客解救和误伤，在第三章验雨中辨真的提示。M4 在目标 Android 硬件上复跑，记录设备、画质、帧时间与峰值 PSS。最密集 L4 段的目标为 PC 60 fps、Android 标准档至少 30 fps。
